## 已验证入口

- 后台：`uv sync` 安装，配置不同的工作人员/终端令牌后 `bash scripts/backend.sh` 启动；终端中断停止，日志为 `logs/backend.log`。隔离数据库的本地运行已验证健康接口和正常停止。
- 后台测试：`uv run pytest -q`，目前二十一项通过。本执行环境内测试客户端在沙箱中停于事件循环唤醒，同一组测试在沙箱外通过，具体差异已检查线程堆栈。
- 固件：加载本地 ESP-IDF 环境后 `bash tools/build.sh`；新增源文件后需重新配置构建。ESP-IDF 5.4.1 完整构建通过，日志为 `logs/firmware-ble-build.log`。
- 游戏测试：`bash scripts/test-firmware.sh`，锁定、错误恢复、三片通关、收藏和复玩通过。

本轮没有烧录、擦除或操作 K230；原始参考压缩包仍保留且未纳入本轮提交。

## 下一段实现

在已有身份读取和到访权限之上，实现设备端授权解锁、可信设备响应及后台不回退的进度同步，再接入工作人员页面。后台不得通过工作人员手工布尔值宣称设备已执行，不得从模拟到访向实物发出命令。之后完成电脑看板、AI 和情景推演，并逐项进行实机及持续展示验收。
