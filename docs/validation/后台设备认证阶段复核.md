# 后台设备认证阶段复核

采用非隔离双轴顺序复核，当前 Agent 执行，不是独立 Agent 验收。比较命令 `git diff c975c86...HEAD`，实现提交 `cf3ecf6`。依据用户项目规则、开发实施基线第 4.3、5 节和腰牌认证消息契约。

## 规范轴

密钥以 `SecretStr` 保存，私有配置不通过接口返回。认证消息含方向和版本前缀，固定长度并验证 MAC、挑战和请求编号。认证码采用恒定时间比较；进度标志验证收藏不变量，数据库写入处于事务中。设备接口与到访统计分离，无新增规范违反或必须立即处理的代码异味。

补充一项验收覆盖：重新创建后台后读取已认证收藏，以及原回执重试不刷新认证时间。该测试通过，不需要修改实现。

## 需求轴

“解锁已发送不等于游戏已解锁”由授权不改变命令状态、认证回执才确认保证；“已完成状态不得被较旧后台状态回退”由有效标志按位合并保证。身份错误、认证错误、无密钥和过期挑战明确拒绝。无到访不能从本接口创建新解锁命令，查询进度也不会解锁。

固件随机数、授权执行、认证响应和手机转发尚未接入，当前不能证明真实设备确认或设备端防重放；二十一项后台测试只证明软件接口和协议夹具的行为。

## 结论

规范轴零项发现；需求轴在本阶段无错误实现，完整跨端要求仍未验收。下一阶段实现固件认证与随机数失效，并保存实机证据。
