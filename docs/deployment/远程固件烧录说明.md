# 长安游迹远程固件烧录说明

## 适用硬件与版本

适用于与当前已验证设备相同的ESP32-S3圆屏吧唧，闪存16MB。不同屏幕、触控或音频接线的ESP32-S3板不能仅凭芯片相同直接使用。

本包为2026年10月3日完整单游戏流程固件，包含封面、选游戏、玩法说明、继续／重玩、通关庆祝及网页实时联动；应用文件与本地最后一次成功烧录的文件一致。最新文件名：`changan-youji-20261003-flow-v4.tar.gz`。

应用文件SHA256：`e1516912877b5d289f9c7ec46b76caf61ea3390cafd0b9cc4161ee3946ebba14`。

包内不含设备备份、网页服务、DeepSeek密钥或本地环境配置。网页入口：<https://babelbeast.com/xks>。

## 完整烧录

解压后保留目录结构。烧录工具选择ESP32-S3，闪存16MB，模式DIO，频率80MHz。串口按远程电脑实际识别结果选择，不能照抄本机端口。

| 地址 | 文件 |
| --- | --- |
| `0x000000` | `bootloader/bootloader.bin` |
| `0x008000` | `partition_table/partition-table.bin` |
| `0x00D000` | `ota_data_initial.bin` |
| `0x010000` | `srmodels/srmodels.bin` |
| `0x100000` | `xiaozhi.bin` |

包内`flash_args`和`flasher_args.json`来自本次ESP-IDF构建，以上地址不是推测值。使用支持上述参数文件的ESP-IDF esptool.py环境，在解压目录执行：

```sh
esptool.py --chip esp32s3 --port COM10 --baud 460800 write_flash @flash_args
```

用户提供的远端ESP-IDF位于`/home/lidong/esp/esp-idf`，版本6.0.2。压缩包放在`/home/lidong`时，可使用新版esptool命令直接烧录，不运行`idf.py build`：

```sh
source /home/lidong/esp/esp-idf/export.sh && \
cd /home/lidong && \
tar -xzf changan-youji-20261003-flow-v4.tar.gz && \
cd changan-youji-20261003-flow-v4 && \
sha256sum -c SHA256SUMS.txt && \
esptool --chip esp32s3 --port /dev/ttyACM0 --baud 460800 \
  --before default-reset --after hard-reset write-flash \
  --flash-mode dio --flash-freq 80m --flash-size 16MB \
  0x000000 bootloader/bootloader.bin \
  0x008000 partition_table/partition-table.bin \
  0x00D000 ota_data_initial.bin \
  0x010000 srmodels/srmodels.bin \
  0x100000 xiaozhi.bin
```

将`COM10`替换为实际端口，例如Windows的`COM7`或Linux的`/dev/ttyACM0`。若使用不同版本的工具，请按对应版本命令名称读取地址表，不自行修改烧录地址。

**不要勾选整片擦除，不执行`erase_flash`。** 分文件烧录仅改写指定区域；整片擦除会删除保存的游戏进度、收藏及其他设备配置。完整烧录会重置OTA选择信息到本包应用分区；仅同一硬件且采用本包分区布局时使用。未提供合并整片镜像，避免镜像填充区域覆盖设备配置。

## 仅更新应用

只有确认目标设备已经使用相同分区表、启动文件与资源，并且当前启动应用位于`0x100000`时，才能只写`xiaozhi.bin`：

```sh
esptool.py --chip esp32s3 --port COM10 --baud 460800 write_flash --flash_mode dio --flash_freq 80m --flash_size 16MB 0x100000 xiaozhi.bin
```

不确定目标固件来源或分区布局时，使用上面的完整5文件方式。

## 文件校验与烧录后

包内`SHA256SUMS.txt`记录所有烧录文件及参数文件的校验值。Linux可在解压目录执行`sha256sum -c SHA256SUMS.txt`；Windows可用`Get-FileHash .\xiaozhi.bin -Algorithm SHA256`与本文应用校验值比较。

烧录完成后复位设备，应进入“长安游迹”城门封面。点击“开始探索”进入单游戏选择，再进入秦俑玩法说明。游戏使用三片拖拽拼图，设置或退出返回不清空已放碎片，“重新开始”才重置本次拼图。

新版网页连接后显示腰牌当前页面与拼接进度；旧版固件仍可认证同步，但不会伪造实时页面。远端更换固件后请刷新网页并重新连接。

另一块设备有自己的真实身份，不会因烧录相同固件自动成为网页的001号。若要在现有公网网页同步远程新设备，需要按真实设备身份登记对应编号；不要冒用当前001号身份。
