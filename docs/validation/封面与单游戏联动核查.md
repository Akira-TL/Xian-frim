# 封面与单游戏联动核查

## 范围与结果

本轮只完善《秦俑归阵》，不新增《城门寻宝》或《诗句补全》。封面、选游戏、玩法说明、游玩、通关庆祝、收藏、展示及设置返回均已实现；网页只增加实时页面和拼接数量，不添加调试说明或记录列表。

新封面使用内置imagegen生成，原图及实际提示词见`docs/design/游戏封面素材与流程.md`。圆屏素材360×360，网页消费版本480×480约23KB；圆屏构建使用LVGL压缩格式，不把生成原图装入固件。

## 确定性检查

- `scripts/test-qin-render.sh`：六张正式素材均产生实际可见像素，新封面改变9720个测试屏幕像素。
- 正式生产页面通过LVGL指针输入拖完三片，进入通关庆祝，然后查看收藏、设为展示并返回封面。
- 设置返回及退出后重新选择游戏保留已放碎片；主动“重新开始”才重置本次拼图。对原有解锁、收藏和展示状态无清空操作。
- 网页隔离网关8项检查通过，设备控制10项检查通过。实时消息不直接修改认证进度，必须通过原有签名回执回读；另一设备的遥测、越界碎片和不完整快照被拒绝。旧固件不伪造实时界面。
- 固件游戏／认证独立检查通过，固件构建、网页类型检查和生产构建通过。

首次新增网页测试失败原因是隔离测试文件只配置8个设备身份，新增第9、10个身份无测试密钥。已只补充隔离测试固定密钥并重跑成功，没有改动生产密钥或降低认证要求。
