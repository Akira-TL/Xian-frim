# 秦俑正确放置音效接入记录

2026年10月3日，补齐有效 PRD 2.0 第 8.1 节的正确放置短促音效。此前仅有碎片就位及文字反馈，不能因为设备有扬声器就认为声音反馈已完成。

## 实现与边界

- `pg_exploration.c` 仅在 `exploration_place` 返回 `ESP_OK` 且结果为 `QIN_PLACED`、`QIN_COMPLETED` 或 `QIN_REPLAY_COMPLETED` 时请求音效。拖错、无效放置、锁定及保存失败不触发。
- `ui_tool_play_game_sound` 通过现有主事件任务异步播放，不在触摸回调内等待音频解码队列；不影响游戏状态或奖励数量。
- 复用现有 `main/assets/common/popup.ogg`，约 0.487 秒、1148 字节，无新增音频资源。请求和实际播放前都检查音量；零音量静音。
- 游戏专用启动路径仍初始化音频服务和主事件任务，不进入旧配网、语音终端或原版应用页面。
- 烧录不执行擦除闪存，不清除游戏 NVS；已有收藏和进度不主动修改。
