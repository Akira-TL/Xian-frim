# 看板活动快照接口

`GET /api/v1/activity?source=physical_scan_simulated_site` 返回 `map`、`visits`、`trend_estimates` 和 `progress`。后台需要工作人员令牌；浏览器的免登录同源入口由网页服务保管内部令牌，不要求用户登录。

## 统计口径

- `visits` 汇总固定会话 `demo-001` 中所选来源的全部有效到访，不限最近五分钟。只纳入时间可靠且采集时间不晚于快照时间的持久化记录；扫码入口已经按既有规则合并同腰牌同节点六十秒内的重复扫码。累计次数不是当前在场人数。
- `visits.total_visits` 为累计有效到访次数，`participating_badges` 为至少出现一次有效到访的不同腰牌数，`sites` 逐节点提供累计次数，其和等于累计有效到访。
- `interval_samples` 为同一腰牌相邻时间可靠有效到访组成的样本对数，包含跨节点及同节点再次到访，不在不同腰牌之间相减。按采集时间排序，与记录读取顺序无关。`average_scan_interval_seconds` 为这些时间差的算术平均值，单位秒；没有样本为 `null`，同一时刻的有效样本可为零秒。排除不可靠时间后比较剩余有效记录，不用于还原被排除记录的顺序或实际停留时长。
- `excluded_untrusted_events` 与 `excluded_future_events` 分别说明累计范围内被排除的时间不可靠记录与未来时间记录；不会把它们静默当作可靠扫码。汇总和地图使用同一读取事务与同一快照时间，历史记录不会因热度过期被删除。

- `map` 沿用地图接口的五分钟窗口、时间质量、演示热度阈值与来源隔离，不能解释为实际在场人数。
- `progress` 统计固定会话 `demo-001` 中具有 A 点实物来源到访的不同腰牌，游戏固定为 `qin_formation`。同一枚腰牌不会因重复到访或重复回执被多计。
- `eligible_badges` 是符合上述到访条件的腰牌数；`verified_badges` 是其中至少具有一次认证状态回执的腰牌数。认证到未解锁状态也可以增加认证数，不增加解锁数。
- `unlocked_badges`、`completed_badges`、`collected_badges`、`exhibiting_badges` 只来自后台验证通过并持久化的设备状态。请求已创建或已发送不算执行、完成或收藏。
- `last_verified_at` 是纳入统计的状态记录中最近一次认证时间；没有认证记录时为 `null`。这是后台最后收到的状态，不表示设备当前在线。
- 地图观察记录和进度聚合在同一 SQLite 读取事务内取得，避免并发写入造成同一响应中口径不一致。

选择 `source=generated_simulation` 时，地图只统计生成模拟数据，`progress` 为 `null`，表示实物游戏进度不适用，不能展示为实物完成零枚。

目前没有人工核验记录接口。看板应显示“人工核验未启用”，不能把设备认证数冒充人工核验数。游戏完成率按设备确认完成数除以设备确认解锁数计算；分母为零时显示“暂无可计算数据”。

## 下一窗口趋势估计

`trend_estimates` 按 A/B/C 返回三个节点的确定性计算结果，与 `map.trend` 的观测曲线和独立情景推演分开。后者不能替代此估计。

- 当前窗口为 `(快照时间 − 300秒, 快照时间]`，前一窗口为 `(快照时间 − 600秒, 快照时间 − 300秒]`。仅纳入同一会话、同一来源且时间可靠的已合并有效到访；未来、其他来源及其他会话不参与。
- `current_window_visits`、`previous_window_visits` 统计到访次数，不是不同腰牌数；同一腰牌在短时去重范围之外的再次有效到访分别计入。
- `estimated_next_visits = (7 × current_window_visits + 3 × previous_window_visits) / 10`。字段 `current_weight=0.7`、`previous_weight=0.3`、`window_seconds=300` 显式提供假设，单位为次有效到访／五分钟；目标窗口为快照之后五分钟。
- 两窗各至少一条可靠到访且节点状态新鲜时 `status=ready`。样本不足为 `insufficient_samples`；缺失、过期、时间不可靠分别为 `missing`、`stale`、`untrusted`。不可估计时 `estimated_next_visits=null`，不以零替代未知。
- 网页与后台断开时，不继续展示旧快照估计值，显示“暂不估计（后台未连接）”。

这是明示权重的简单统计估计，不是训练的人流预测模型，不提供未经验证的准确率或拥堵概率，不参与真实解锁、推荐候选热度或现场安全决策。此新增字段仅位于电脑／手机活动快照；K230现有地图查询契约不变。

## 边界与验证

未授权或使用终端令牌访问后台返回 `401`，未知来源返回 `422`。网页代理白名单已开放活动快照的只读查询，浏览器无需令牌；不开放活动快照写入。网页客户端验证响应字段、来源隔离和认证计数约束，不能把错误响应当作可显示数据。

`tests/backend/test_activity.py` 通过公开接口验证空快照、已发送不计认证、重复回执去重、生成来源隔离和权限。设备回执由独立编码的测试设备替身生成；这些测试不证明真实安卓蓝牙连接或实物通关已经验收。
