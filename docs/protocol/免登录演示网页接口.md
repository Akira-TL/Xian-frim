# 免登录演示网页接口

用户确认演示参与者无需登录，调试也不输入工作人员令牌。浏览器访问网页自身的 `/api/v1/`；Next.js 服务端用 `CHANGAN_OPERATOR_TOKEN` 向本机后台请求，内部令牌不返回给浏览器。`CHANGAN_BACKEND_ORIGIN` 默认 `http://127.0.0.1:8000`，不可含凭据、路径、查询或片段。

## 开放范围

- 查询：登记列表、到访列表、解锁请求列表、地图、看板活动快照、指定腰牌已认证进度。
- 操作：登记腰牌、创建解锁请求、标记已发送、生成设备授权或查询挑战、提交原始认证回执。
- 演示调试：`POST /api/v1/demo/visits` 只产生 `generated_simulation` 来源，不能控制实物腰牌。
- 假设计算：`POST /api/v1/simulation` 返回独立情景推演，不写入活动记录；所有演示参与者均可调用。
- 不开放：终端实物到访上报、终端心跳及地点配置接口、任意其他后台路径。免登录不赋予景区终端身份。

身份匹配、到访来源和设备认证均由既有后台契约校验，免登录不取消它们。伪造布尔值不能变成设备进度，未配置密钥返回 503，未取得合法回执的进度查询返回 404。

## 请求与错误

写入要求 JSON，请求上限 16 KiB。只向固定后台地址转交允许的方法和路径，不接受浏览器的访问令牌作为代理身份，不跟随后台重定向。未知路径返回 404；跨站写入返回 403；大小超过限制返回 413；非 JSON 返回 415。后台响应保留状态码与内容类型，设置 `Cache-Control: no-store`，不复制后台身份凭据或 Cookie。后台超时／不可达返回 502，并明确结果未确认。

页面同源写入无需用户账户。部署反向代理时将 `CHANGAN_PUBLIC_ORIGIN` 配置为实际 HTTPS 来源，以便核对浏览器 `Origin`；不要把手机入口设为手机自身的 `localhost`。可信 HTTPS 与安卓设备选择仍待实机部署验收，当前网页仅监听本机。

## 隔离测试

先在 `services/web/` 执行 `npm ci` 和 `npm run build`，然后在根目录运行 `bash scripts/web/test-gateway.sh`。脚本使用固定测试端口 8123、3101、临时数据库和专用测试令牌，仅载入 `services/web/tests/fixtures/device-keys.test.json` 的公开测试夹具密钥，不载入实物设备密钥；结束停止它启动的服务，数据库在输出的 `/tmp/changan-gateway.*` 路径保留。公开接口日志为 `logs/web-gateway-test.log`，认证操作日志为 `logs/web-control-test.log`，另有网页和后台运行日志。夹具密钥严禁用于真实腰牌或生产后台。

公开 HTTP 六项测试覆盖免登录查询与登记、活动快照及模拟来源边界、假设计算与事实隔离、合法浏览器同源 `Origin`、终端路径隔离、未认证进度、缺少对应设备密钥、伪造报告、跨站与请求大小限制。另有七项公开认证操作测试。该测试不替代手机 BLE 连接或真实设备回执证据。
