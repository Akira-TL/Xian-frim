# DeepSeek 服务接入

手机端仍是免登录网页，不开发或安装 Android 应用。模型请求只从后台发送。

## 服务与密钥

使用 `https://api.deepseek.com/chat/completions` 和 `deepseek-flash`，按[官方聊天补全文档](https://api-docs.deepseek.com/api/create-chat-completion/)调用；按[官方 JSON 输出说明](https://api-docs.deepseek.com/guides/json_mode/)启用 `response_format=json_object`，提示包含 JSON 格式示例。关闭思考模式，最多1024个输出令牌，不向用户展示思考过程。

用户提供的根目录 `.key` 已迁移至被忽略的 `data/deepseek.env`，原路径已移除，文件权限为600。文件仅包含 `DEEPSEEK_API_KEY=密钥` 一行。不要把密钥复制到网页、固件或命令行参数，不把文件纳入 Git，也不要向聊天发送密钥。迁移没有丢弃密钥，私有文件仍保留，可由用户管理。

`create_app_from_environment` 默认读取该私有文件；没有文件时仍按未配置降级。可用 `CHANGAN_DEEPSEEK_KEY_PATH` 指定文件，显式路径缺失或格式／权限错误会阻止启动，不静默改为未配置。`CHANGAN_DEEPSEEK_ENABLED=0` 禁用实网模型；只接受0或1。隔离网页测试脚本固定禁用，避免无意使用真实凭据或产生费用。

## 行为边界

只发送已构造的输入快照，不发送腰牌身份、访问令牌或设备私有密钥。结果继续经过既有字段、快照、候选及时效校验。后台八秒等待和取消仍由推荐业务层执行，HTTP 请求非阻塞且可取消；连接超时三秒。不自动重试或跟随重定向，避免重复费用及凭据被转发。

非成功状态、无效服务响应或响应超过65536字节转为服务不可用的明确规则降级，不回显服务返回或异常详情。只有完整结束的消息内容才交给业务层；消息内容本身若不符合推荐契约，仍按输出校验失败降级。原始内容的私有审计规则不变。

适配器测试使用外部 HTTP 替身，不能作为真实请求或网页显示证据。实网调用、实际网页显示和安卓实机仍须分别验收。
