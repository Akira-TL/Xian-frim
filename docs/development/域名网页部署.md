# 域名网页部署

手机入口：`https://babelbeast.com/xks`；电脑看板：`https://babelbeast.com/xks/dashboard`。所有参与者免登录使用网页，不安装手机应用。手机使用支持网页蓝牙的安卓 Chrome，连接腰牌时仍须用户点击授权。

Next.js 的 `basePath` 固定为 `/xks`，静态资源、链接和浏览器接口均使用该前缀。修改前缀后必须重新构建，不能仅修改 Nginx。依据：[Next.js 官方说明](https://nextjs.org/docs/pages/api-reference/config/next-config-js/basePath)。

Nginx 在现有主域名 HTTPS 服务中只引入 `infra/nginx/xks-location.conf`，不替换其他站点、证书和根路径。前缀原样转发至本机 `8041`；网页服务通过内部凭据连接本机后台 `8040`。两个端口仅用于本次演示，未分配永久项目端口段。公网不直接转发后台端口或私有审计接口。

服务配置在 `infra/systemd/changan-demo.service`，安装至 `/etc/systemd/system/changan-demo.service` 后由 systemd 管理。启停通过项目脚本：

```sh
bash scripts/domain-demo.sh start
bash scripts/domain-demo.sh status
bash scripts/domain-demo.sh stop
```

数据库使用 `data/changan.sqlite3`，实物认证密钥使用已有 `data/device-keys.json`，模型密钥使用 `data/deepseek.env`。均不公开、不提交。启动不会清空腰牌或数据库进度。运行日志在 `logs/`。服务首次启动生成共享内部令牌，不交给浏览器。

构建与隔离契约验证：

```sh
cd services/web
npm run typecheck
npm run build
cd ../..
bash scripts/web/test-gateway.sh
```

部署时先执行 `sudo nginx -t`，成功后才重新加载 Nginx。安装后的配置只在主域名现有 HTTPS server 中增加一行 include；撤销该行并重新加载即可撤销公网入口，原站点无需恢复或替换。
