# 游戏封面素材与流程

## 本轮范围

用户确认本轮只完善《秦俑归阵》，另外两个游戏后续再加；不添加可点击的假游戏或改变其他地点解锁权限。

入口封面 → 开始探索 → 游戏选择 → 秦俑玩法说明 → 开始／继续 → 拖拽拼图 → 通关庆祝 → 收藏／展示。游戏与设置返回不清空已放碎片；重新开始是明确的独立操作。

网页保持紧凑，只增加连接设备的当前页面和三片拼图进度。实时页面信息只作当前蓝牙会话的展示，不替代原有认证回执，不写入到访、收藏统计或模型推荐。通关与展示仍自动回读原有认证状态；断开连接清空实时显示。

## 生成方式与保存路径

使用内置 imagegen，非命令行备用方式。新封面原图：`assets/design/journey-cover-v1.png`。

- 圆屏消费：`assets/qin/cover.png`，360×360；构建转为LVGL压缩图片。
- 网页消费：`services/web/public/images/journey-cover-v1.webp`，480×480。
- 既有秦俑与拼图已由imagegen生成，继续复用，不覆盖角色或切片。
