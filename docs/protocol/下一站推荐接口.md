# 下一站推荐接口

`POST /api/v1/recommendations` 输入只包含 `badge_id`、`event_id`，后台需要工作人员令牌。不能在请求中提交完成布尔值、候选地点、开放状态或热度来覆盖后台事实。

## 当前阶段

当前交付候选构造、明确标注的规则降级、持久化历史快照、网页同源免登录查询、手机页和电脑看板展示，以及模型输出字段／候选校验、八秒等待时限、明确服务故障降级和成功建议／过期／取消私有审计，**没有调用真实外部模型**。未配置模型、有有效候选时 `source=rule_fallback`、`fallback_reason=not_configured`；无合格候选时 `source=none`、`fallback_reason=no_candidates`，`selected_site=null`，儿童文案为空。模型通路使用外部服务替身验证，生产启动尚未配置适配器。后续还须接入真实服务和实际调用／显示证据。不得将当前阶段宣称为 AI 模型验收通过。

网页代理只开放生成建议和按快照编号回读历史。浏览器客户端验证字段、来源、快照编号一致性、模拟数据不带实物进度，以及最终地点属于有效输入候选；不开放终端写入或手工覆写推荐结果。

## 模型输出校验接口

后台工厂可注入 `RecommendationModel` 外部服务边界；生产启动仍未配置适配器，不调用模型。测试替身不计入真实模型验收。

模型只接收输入快照副本，不含腰牌、实物身份、访问令牌或私有密钥。返回只能包含 `snapshot_id`、`selected_site`、`child_text`、`operator_reason`；拒绝未知字段、非 JSON、空白或超长文案、错快照、候选之外的地点。原始输出长度上限4096字符，儿童文案最多200字符，工作人员理由最多500字符。

合法结果为 `source=model`、`fallback_reason=null`；失败为 `source=rule_fallback`、`fallback_reason=invalid_output`，理由明确模型输出校验失败。所有结果仍持久化，历史回读不代表本次模型调用。网页按返回来源显示校验通过的模型建议或具体规则原因，不默认把所有规则结果标为未配置。

模型异步等待最长八秒；超时取消请求并返回 `fallback_reason=timeout` 的明确规则建议，理由和界面均标注八秒内未返回。晚到结果不能恢复为成功；调用方取消时也取消模型任务，晚到异常不写入日志或公开回应。外部适配器必须采用可取消、非阻塞的异步网络请求，不能用阻塞函数占用事件循环。

保存与返回前再次检查原快照有效期。输入已过期时返回 `409`，不把模型结果或规则结果当作当前可用建议，也不延长原有效期。

连接等 `OSError` 网络错误，或适配器明确转译为 `ModelUnavailable` 的服务故障，返回 `fallback_reason=unavailable` 的规则建议，理由及网页标注“服务不可用”。不回显异常详情、服务地址或凭据，不将异常字符串存进公开历史，也不记录其日志。适配器应只转换明确的外部故障，不将任意程序缺陷转成服务不可用；推荐层不兜底吞掉所有异常。故障降级仍受原快照失效时间限制。

当前字段校验只能核验结构、候选和快照；不能凭此证明模型每句文化内容或理由都真实。真实模型服务及实际调用／显示证据仍需继续交付。故障及八秒测试使用外部服务替身，不是实网可用性或响应时间证据。

## 受保护的原始返回审计

新产生且在后台成功保存的建议或规则降级会在同一 SQLite 写事务中保存 `recommendation_audits`。审计包含最终结果及其完整输入、记录时间、是否调用模型边界、原始返回、完整返回的 SHA-256 摘要、截断标记和校验状态。状态区分未调用、接受、输出无效、超时、服务不可用。异常详情不记录；超时和服务不可用没有收到可审计返回时，原始返回为空，不补造内容。后台保存不证明浏览器已经显示，显示证据仍需另外核验。

原始返回最多保留4096字符；更长输出已被拒绝，审计只保留前缀、完整摘要和 `raw_truncated=true`，不能把截断文本当作完整返回。审计文本是不可信内容，不在网页渲染或写入普通日志。

`GET /api/v1/recommendations/{snapshot_id}/audit` 只接受后台工作人员凭据；终端和匿名请求为 `401`。免登录网页代理不开放该路径，返回 `404`。公开推荐与历史接口不增加原始返回字段。旧记录没有审计时返回 `404`，不通过回读补造原始返回或新的模型请求。

`model_attempted=true` 只证明调用过注入的模型边界，测试替身也会如此；不是实网调用证明。成功建议审计和下述过期／取消记录跨重启保持。本阶段仍需真实服务、真实调用和显示证据，不得据此宣布模型验收完成。

## 过期与取消的拒绝记录

模型等待结束后，若输入已过期，仍返回 `409`，且不写入有效建议表；该快照的公开历史查询仍为 `404`。同时在独立的 `recommendation_rejections` 表保存拒绝记录，不修改既有建议或审计表、不删除旧数据。

`GET /api/v1/recommendation-rejections` 仅供后台工作人员凭据查询最近一百条拒绝记录，按保存顺序倒序返回。终端和匿名请求为 `401`；免登录网页代理不开放，返回 `404`。此接口不是有效建议列表，也不允许工作人员将拒绝结果改成成功。

每条记录包含腰牌和到访编号、完整输入快照、记录时间、`reason=expired`、模型边界是否调用、原始返回及摘要／截断标记、输出校验状态。`validation=accepted` 仅表示字段与候选校验通过；记录的 `reason=expired` 表示它仍因时效被拒绝，不能展示为当前建议。返回文本采用成功审计的相同限制：最多4096字符，超长只保留前缀和完整摘要；不包含异常详情、不在网页渲染，也不写入普通日志。

候选构造之前的未知到访、身份不符及旧事件拒绝未调用模型，不在本表制造模型尝试记录。过期拒绝保存失败时不能声称已经留存审计。测试用替身推进时钟，验证拒绝记录和重启回读；不代表实际模型延迟或实网调用。

服务端在等待模型时实际收到 `asyncio.CancelledError`，会取消模型任务，并保存 `reason=cancelled`、`validation=cancelled` 的拒绝记录后继续传递取消异常，不转换成规则建议或成功回应。此时尚未取得可用返回，原始返回和摘要为空，截断标记为假；不补造返回，也不在晚到成功后改写记录。输入快照、腰牌和到访编号仍保留，供后台私有查询。

此行为不等同于任何浏览器断网都会取消服务端任务。网络连接中断可能不触发应用任务取消；当前测试通过公开 HTTP 应用接口实际取消请求任务，并让外部模型替身晚到返回，验证拒绝记录保持且不产生有效历史或命令。后台崩溃、被强制结束或数据库写入失败时不能保证取消记录落盘，不宣称具有断电事务恢复证据。

## 输入快照与过滤

所选到访必须属于该腰牌，时间已校准、不晚于后台时间、未达到九十秒。出现更晚的同来源可靠到访时，不能使用旧事件锚定地点。未知事件为 `404`，身份或时效冲突为 `409`，字段错误为 `422`，未授权或使用终端令牌为 `401`。

统计与该腰牌的认证进度在同一 SQLite 读取事务内取得；到访源自哪个数据集，就只使用同一来源的统计和已到访节点。生成模拟数据不包含实物认证进度。实物完成记录只来自已验证设备回执，不读取工作人员传入的布尔值；最后认证时间不意味着设备现在在线。

候选必须满足：

- 在 [演示节点配置](演示节点配置.md) 中开放，且从所选到访地点可达；默认可达关系是模拟园区假设。
- 统计状态新鲜、时间可靠，距离观测更新时间不足九十秒；缺失、过时、不可靠或未来数据不当作低热度。
- 不包含已经认证完成的《秦俑归阵》任务。B/C 没有已接入小游戏，不能凭到访推断完成；内容提示保留未实现标记。

快照包含唯一 `snapshot_id`、会话、数据来源、生成和失效时间、配置版本、选定到访地点、已到访节点、认证完成任务、认证时间，以及每个候选的完整配置与统计。快照最长三十秒，并受所选到访和候选数据最早失效时间限制；界面不得使用过期快照作为新建议。

## 当前规则

从有效候选优先选择尚未到访的节点，再选择最近五分钟去重腰牌数较少的节点，相同条件按 A/B/C 顺序确定。这个顺序只用于演示，没有真实场地拥堵或安全含义。

返回 `selected_site`、儿童一句话和工作人员理由，均绑定 `snapshot_id` 与完整输入。工作人员理由明确“AI 未配置”，显示所用五分钟腰牌数，B/C 额外标注小游戏尚未接入。建议可拒绝，不自动解锁、不补造到访。

## 持久化与历史回读

返回成功前，输入和最终结果整体写入 SQLite 的 `recommendations` 表，关联原腰牌和到访。只新增该表，不改写原到访或进度；现有数据库启动时可重复创建。每次生成使用新的快照编号，不用上次建议冒充新的生成。

`GET /api/v1/recommendations/{snapshot_id}` 供工作人员和终端查询历史记录，返回 `delivery=historical`、`retrieved_at`、`expired` 与原始 `result`。回读不刷新原生成/失效时间，不重新推荐；历史结果即使原来源为模型，也不能表示本次发生了实时模型请求。未知编号为 `404`，未授权为 `401`。

`tests/backend/test_recommendations.py` 的十四项公开接口测试覆盖缺失候选、规则来源、关闭/不可达/过时、跨来源、选定到访时效与更新、认证完成、输入改变后的建议变化、事实隔离、权限及重启后的历史回读。设备认证部分使用独立测试回执，不是安卓实机或真实模型证据。
