# 三分钟演示说明

2026年10月3日。当前为三游戏v5与个性化网页路线版本；下表是180秒讲解计划，不是已计时完成的现场演练。连续30分钟和三轮主流程由用户取消，不补测、不宣称通过。外壳建模由用户或其负责方处理。

## 演示准备

1. 设备烧录 `releases/changan-youji-20261003-games-v5.tar.gz`，远端只需烧预编译二进制，见[完整指令](../deployment/远程固件烧录说明.md)。旧v4有出厂地址绑定，不能仅刷新网页解决远端不匹配。不要整片擦除或清收藏。
2. 手机打开 `https://babelbeast.com/xks`，选择001号，点击“连接腰牌”并选 `DOIT_TT`；先认证读回已有进度。演示模式不核对出厂地址，仍须真实设备回执。同包共享001编号，不代表独立游客。
3. 电脑打开 `https://babelbeast.com/xks/dashboard`。`bash scripts/domain-demo.sh status` 检查服务，必要时通过同一脚本启动。不要投屏密钥或原始私有审计。
4. 已解锁或已收藏就按复玩讲解，不假称新领取、新解锁或新奖励。新设备未解锁时，可在已连接腰牌的“演示解锁”中创建A点测试打卡，再点击解锁；测试打卡不等于K230摄像头扫码。
5. 无对接方现场观测时，手机路线页使用明确标注的演示热度。电脑可点击“生成演示数据（非真实到访）”准备虚拟记录，默认A/B/C为6/3/1枚，九十秒后重新准备，不延长旧记录。手机路线情景输入与电脑生成活动记录是不同数据，不要求数字相同。

若蓝牙授权或网络超过计划时间，如实延长或略过展示，不用假回执赶进度。三游戏软件交互已有正式LVGL指针回归；这不是实物触摸录像或三分钟现场计时证据。

## 故障与备用

- 连接失败：重连并先认证查询；旧偶发失败尚未证明根因彻底修复，不清存储或手机蓝牙数据。
- 发送未确认：只说未确认，不重复宣布执行成功。已解锁游戏可继续本地玩。
- 模型失败：展示实际规则来源或无建议；历史建议不可冒充本次AI调用，过期热度不当作当前观测。
- 缺现场扫码：明确接口测试或生成模拟，不宣称K230程序、识别率和七英寸显示已完成。
- 备用录像：只能使用真实设备操作录像，标版本和录制时间。当前没有腰牌触摸操作视频；网页录屏、截图、生成插画都不能替代。
