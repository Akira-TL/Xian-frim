# 演示网页运行

## 安装与运行

根目录执行 `uv sync` 安装后台依赖；`services/web/` 执行 `npm ci` 安装网页依赖。

在根目录运行 `bash scripts/demo.sh dev` 启动免登录演示。电脑访问 `http://127.0.0.1:3000`，不需要账户或访问令牌。两个服务仅监听本机；手机不应使用这个地址，手机 HTTPS 入口尚待配置。默认脚本加载存在的 `data/device-keys.json`，密钥只供后台认证，网页不取得密钥。

脚本为本次运行生成两个不同的随机内部通信令牌，分别供网页与景区终端后台边界使用，不打印、不写入浏览器。重启令牌会变化，不影响已持久化的到访和进度。对接方需要稳定终端令牌时，在启动环境预先配置两种令牌；不能用网页的公开接口冒充终端上报到访。

生产构建在 `services/web/` 执行 `npm run build`，之后根目录运行 `bash scripts/demo.sh start`。停止使用终端 Ctrl+C；任一服务退出，脚本停止另一个，不保留后台服务。网页日志在 `logs/web-dev.log` 或 `logs/web-start.log`，后台日志在 `logs/backend.log`。

## 当前页面与边界

页面提供登记、到访选择、来源标注和解锁请求状态查看。实物扫码与生成模拟分开显示；登记不等于到访，更不等于已解锁。身份绑定不可覆盖。

蓝牙连接、实物身份自动读取、授权发送与认证回执仍在下一阶段接入；当前页面明确显示“设备未连接、执行未核验”，不会发出设备指令。不能据网页可访问推断手机实机链路已经通过。

## 验证

- `npm run typecheck`：网页 TypeScript 检查。
- `npm run build`：完整网页构建。
- `bash scripts/web/test-gateway.sh`：隔离数据库的公开 HTTP 契约测试。
- `npm audit --omit=dev`：生产依赖审计；本轮固定间接依赖 PostCSS 8.5.28、sharp 0.35.5 后为零告警，不能保证之后永远为零。

免登录决策与修补版本选择见 [ADR 0003](../adr/0003-public-demo-web.md)，开放接口及访问限制见[免登录演示网页接口](../protocol/免登录演示网页接口.md)。
