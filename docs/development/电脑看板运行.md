# 电脑看板运行

在 `services/web/` 安装依赖并构建后，根目录运行 `bash scripts/demo.sh start`，电脑访问 `http://127.0.0.1:3000/dashboard`。开发方式使用 `bash scripts/demo.sh dev`。手机操作页也提供看板链接。

看板无需登录，每五秒读取同源活动快照；手动刷新可立即重新查询。实物扫码接口与生成模拟数据分开选择，切换来源不沿用另一来源的快照。默认只有本机入口，本文不表示已开放公网或完成安卓 HTTPS 联调。

## 当前显示

- 节点示意、最近五分钟去重腰牌数、前后窗口变化、演示热度阈值与更新时间。
- 十二个五分钟窗口的到访趋势表，时间窗左开右闭，单位为不同腰牌数。
- 最近十分钟内观察到的相邻节点转移，不能解释为精确轨迹。
- 《秦俑归阵》的认证、解锁、完成、收藏、展示计数；完成率分母为零不计算。
- 来源、快照时间、时间不可靠事件排除数，以及未启用人工核验的说明。
- 下一站建议：选择当前来源的一条腰牌到访后手动生成，查看依据与快照有效期；采纳或拒绝仅为本页选择，不产生到访、解锁或完成记录。
- 独立情景推演：调整 A/B/C 的假设初始人数、每分钟到达率、平均停留分钟数，选择分流原目标、新目标、采纳比例和时长，然后点击“重新推演”。

没有新鲜或可靠记录时热度为灰色“数据不足”，不能把零次合格到访解释为现场无人。生成来源不显示实物进度；设备认证状态不能解释为当前在线。请求失败时保留的旧快照必须与断线提示一起展示。

情景推演使用一分钟步长与明示的离开量公式。默认参数仅供演示，不自动从扫码数推断现场人数。未分流与采用分流两种方案都用虚线绘制，并展示回传参数和生成时间；修改表单不会改写旧曲线，必须重新计算。网络失败清除推演结果，真实到访快照则保留并提示过时，二者不得混用。算法与范围见 [情景推演接口](../protocol/情景推演接口.md)。

推荐区每五秒独立更新到访列表，不自动选取或生成。切换数据来源清除旧建议与选择，切回也不恢复；查询失败提示旧列表并暂停生成与采纳。历史回读与过期限制复用手机页规则。当前 AI 未配置，只展示明确标注的规则建议或无有效候选，不能当作真实模型验收。管理员可通过[节点配置](../protocol/演示节点配置.md)设置演示热度阈值并重启加载；图例读取后台快照，没有在线配置表单。节点卡片只是演示示意，不是真实景区地理地图。

## 验证边界

推荐区域在专用桌面浏览器、隔离数据库和生成模拟记录上检查：真实鼠标／键盘选择来源和到访，生成规则建议；切换来源清除建议，切回不恢复旧选择；停止本次服务后，列表与生成／采纳操作禁用并显示旧列表警告。回读为 `logs/dashboard-recommendation-live.json`、`logs/dashboard-recommendation-source-switch.json`、`logs/dashboard-recommendation-source-return.json`、`logs/dashboard-recommendation-offline.json`，截图为 `logs/dashboard-recommendation.png`。这不代表调用过模型或控制过实物。

网页类型检查与生产构建通过，隔离同源接口测试验证免登录、来源隔离与原有认证操作。专用桌面浏览器已检查节点卡片、趋势表、零分母提示、真实鼠标键盘来源切换与动态正文；截图为 `logs/dashboard-browser-screenshot.png`，生成来源回读为 `logs/dashboard-browser-generated.json`。停止本次隔离服务后，旧快照警告正确显示，回读为 `logs/dashboard-browser-offline.json`；浏览器原始网络错误不直接作为中文界面的提示文字。这些证据不替代手机 BLE 或实物通关验收。

情景推演的专用浏览器检查覆盖真实输入、计算、改参但不计算、重新计算和断线：两分钟全分流显示 A=81/B=19，半分流显示 A=90.5/B=9.5，与手算一致；到访记录仍为空。截图为 `logs/scenario-browser-screenshot.png`，对应回读为 `logs/scenario-browser-result.json`、`logs/scenario-browser-edited.json`、`logs/scenario-browser-fractional.json`、`logs/scenario-browser-offline.json`；虚线属性记录在 `logs/scenario-browser-chart.json`。截图中表单采纳比例已改为0.5但尚未重新计算，回传参数和曲线仍明确为比例1，这是旧结果标注检查，不是参数串用。
