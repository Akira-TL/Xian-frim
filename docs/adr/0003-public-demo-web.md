# 演示网页免登录与依赖修补版本

2026 年 10 月 3 日，用户确认：本系统为网页演示，默认所有打开网页的人都可以操作，调试也按相同方式设置。不增加工作人员登录、浏览器令牌输入或个人账户。

后台仍只监听本机并保留工作人员与景区终端通信令牌；网页服务在服务端向后台转交固定范围内的操作，令牌不进入浏览器。演示参与者无需知道内部通信令牌。此设置不是生产运营权限方案，也不代表允许任意后台路径透传、伪造实物到访、控制错设备或用人工布尔值代替认证回执。对公网发布仍需单独配置可信 HTTPS 地址，并明确免登录演示的操作范围。

新网页优先沿用个人默认技术栈。安装审计确认 Next.js 15.4 最新的 15.4.11 存在严重告警，建议修复版本为 15.5.27，因此首次建立即采用 15.5.27；React 19、TypeScript、Tailwind CSS 4 与 ESM 保持不变。不存在旧网页迁移。安装后的依赖审计及构建结果单独记录，不以版本号推定安全。

参考：[Next.js 安全公告](https://github.com/vercel/next.js/security/advisories/GHSA-2xp9-vwfh-vxw4)、[15.5.27 发布说明](https://github.com/vercel/next.js/releases/tag/v15.5.27)。
