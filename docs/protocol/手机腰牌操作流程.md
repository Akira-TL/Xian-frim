# 手机腰牌操作流程

## 演示前提

手机端只有免登录网页，不安装应用，内部后台令牌不由用户输入。手机打开 `https://babelbeast.com/xks`，选择已登记001号；实物身份核对、认证读取和接口测试解锁已通过 ADB 在安卓手机上完成。正式操作只用已登记身份和设备认证，不以免登录代替身份核对。

K230 由对接方实现和操作，本项目只维护上报契约。没有实物扫码时，可使用用户授权的“测试打卡（A 点）”，明确属于 `interface_test`，不计真实到访；生成模拟仍不能解锁腰牌。最新实物回执已确认解锁、通关、收藏和展示，001号当前演示应按已有进度或复玩说明，不宣称再次首次解锁。

腰牌开机直接进入本项目游戏，不显示原版图片、动画或应用列表。游戏内亮度音量设置返回不重新开始游戏；该设置触控返回的实物记录仍缺。

## 操作顺序

1. 选择已登记腰牌即可核对身份和读取进度，不要求先有到访。解锁时选择对应实物到访或接口测试记录，核对编号、地点、时间、来源与请求状态。切换目标会断开旧连接并清理旧待发操作；操作进行中禁止切换。
2. 点击“连接并核对身份”，浏览器按原素材服务过滤设备，并授权访问新增活动服务。不以 `DOIT_TT` 名称或浏览器设备编号代替出厂身份。
3. 连接后读取实物身份，与登记严格匹配；不同则拒绝任何设备消息写入。匹配后生成只读挑战、写入 19 字节查询、读取 122 字节回执，由后台认证后同步进度，不自动解锁。
4. 只有当前腰牌、`demo-001`、A 点实物到访或明确标注的接口测试记录可以解锁。未连接、未同步、身份不符、生成模拟、其他地点、已解锁或已过期请求，界面禁用解锁。
5. 点击解锁，后台创建或返回该到访的原请求；读取 16 字节设备随机数，取得后台授权，将完整 137 字节请求一次带响应写入，不能拆成多次独立写入。
6. 写入接受后记录 `sent`，仍不表示设备执行。随后读取原始认证回执并转交后台；身份、挑战和认证校验成功，且设备确认解锁，才显示成功并更新后台。
7. 孩子在腰牌点击开始。手机离线不影响已解锁游戏本地完成和收藏。下次连接或点击“认证同步进度”读取完成、收藏、展示及最近认证时间。

普通进度查询不把旧请求更新为已确认。若设备当前已解锁而旧请求尚未确认，分别保留“当前认证进度”和“旧请求状态”，不能手工补填成功。

## 下一站建议

选定到访后可免登录生成建议，不要求先连接设备。页面显示生成来源、快照编号、有效期、儿童文案、工作人员理由，以及可展开的输入统计。模型服务使用 DeepSeek 的 `deepseek-flash`，已有真实请求与网页显示证据；模型故障、超时或返回不合格时明确使用规则降级。候选观测不足或过期时显示无有效候选，不用历史模型记录冒充当前建议。

建议可采纳或拒绝，但选择仅保留在本页，不制造到访、解锁或完成记录。到访达到九十秒、时间不可靠或来自未来时禁止生成；快照失效时禁止采纳。切换到访会清除旧建议和选择，晚到的旧查询不更新新目标。

“核对历史记录”回读持久化结果，明确标注历史，不发起新的推荐、不延长有效期，且不能采纳为当前建议。生成模拟的输入不继承实物认证进度；B/C 的触摸小游戏仍标注尚未接入。

## 超时与重试

设备选择由用户操作；选择后的服务连接与每次认证操作各有十五秒超时。故障、断线或超时使本次连接失效，晚到结果不能继续记录发送或提交设备确认。页面提示结果未确认，必须重新连接、先认证查询，再根据当前状态决定是否需要发送。一个连接内操作串行；不能并发查询与解锁替换回执。

当前安卓实物检查仍出现偶发建链失败：手机显示 `Connection Error: Connection attempt failed.` 时，不能宣称连接、解锁或游戏进度变化已经成功。可重新选择同一实物尝试连接；若持续失败，刷新同一网页后重新选001号、连接并先读进度。此路径已恢复过真实认证，但根因未确认，刷新不是已证实的彻底修复。不要清空游戏数据、手机蓝牙数据或伪造后台状态。

后台授权挑战与设备随机数仍各有三十秒有效期，请求原有效期为五分钟，不因页面重试延长。过期且设备仍未解锁时，需新的实物到访；不能用生成模拟替代。列表刷新失败不推翻已经取得的合法设备回执，页面另行提示刷新问题。

## 已有证据与未验证部分

自动化使用真实本机后台、公开网页接口和外部设备替身，覆盖解锁认证、错身份零写入、模拟来源拒绝、连接先同步、发送与执行分离、晚到超时拒绝及并发操作拒绝。真实桌面浏览器已检查登记、刷新、模拟来源标注与禁用按钮。

安卓实物服务连接、完整解锁写入及真实回执已有证据；用户手机断开后完成通关收藏、更新及硬复位后进度保持也已认证。拖拽实物获用户“能用”反馈，最终图片尚未提供。未收藏时三次断线重连通过；收藏后三份新回执状态保持，但期间有真正连接失败与恢复，不能记为无故障三轮通过。

仍未完成：偶发建链失败根因与稳定性、游戏内设置触控返回验证、实物复玩奖励幂等、连续三十分钟及三轮完整流程。设备替身生成的测试认证码仍不能作为真实腰牌执行证据。具体记录见[首版实现状态](../product/首版实现状态.md)及[收藏后重连与建链失败记录](../validation/收藏后重连与建链失败记录.md)。
