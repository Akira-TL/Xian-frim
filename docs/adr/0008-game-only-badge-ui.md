# 0008：腰牌界面仅保留游戏

## 决定依据

2026年10月3日用户要求设置返回不能导致游戏消失，取消原版固件图片展示，主要只需要游戏。原设置入口跳到旧应用列表，旧设置返回写死跳回旧首页；原启动页还加载旧素材，因此仅改变首页文案不能解决问题。

## 决定

- 设置属于游戏内部视图，只调整亮度和音量；返回恢复进入前的视图，不重新开始游戏。游戏中也能打开设置。
- 正式构建仅编译和注册 `exploration` 游戏页面，不编译旧页面。开机直接进入游戏首页，初始化阶段只清黑屏，不创建旧开机图片。
- 页面切换只接受游戏页面；重复请求保留当前页面实例。旧USB和语音回调不再切入旧应用界面。
- 游戏奖励收藏及其图片替换入口保留。原版图片展示不再可达，但不删除用户参考代码、压缩包或存储素材，不擦除游戏进度。
- 保留设备通信、音频、亮度及USB底层功能；本决定不扩大为整个旧工程的重新编写。

## 验收边界

完整编译和链接验证旧页面退出构建后的依赖；游戏核心测试检查通关、收藏及复玩行为。烧录不擦除游戏非易失性存储，手机网页重新核对实物身份并读取进度。设置触控和屏幕实际显示仍需实物观察，不能将编译或网页回执当作设置触控验收。
