# 腰牌固件首轮实现

## 活动进度

首轮活动固定为 `demo-001`，游戏为 `qin_formation`，奖励为 `qin_guardian`。默认未解锁，只有外部解锁操作才能开放游戏；复玩保留已有收藏。

非易失性存储（Non-Volatile Storage, NVS）使用独立命名空间 `exploration`，单个 `progress` blob 保存版本、活动编号、解锁请求编号和解锁／通关／收藏／展示标志。当前 schema 为 1，未引入原设置命名空间迁移。发现无效版本或损坏状态时拒绝开放游戏，不自动清空原记录。

存储提交成功后才更新可见的通关与收藏状态；最后一片拼接存储失败时可以重试。中间拼接位置不持久化，重新进入游戏从三片待选状态开始，但已解锁和已收藏状态保持。

## 验证范围

`bash scripts/test-firmware.sh` 验证锁定、错误选择、三片通关、展示和复玩规则；固件构建验证 ESP-IDF 集成。实机触摸、断电保持、中文显示及跨端控制仍须实际联调，不能由主机测试代替。
