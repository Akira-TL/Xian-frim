# 活动到访汇总接入记录

## 覆盖要求

2026年10月3日，补齐PRD第14.1节的节点累计到访人次、活动参与腰牌数及扫码间隔。正式入口为 `https://babelbeast.com/xks/dashboard`，新增“当前活动到访汇总”。统计口径与字段见 `docs/protocol/看板活动快照接口.md`。

这是同一活动来源的累计汇总，不是最近五分钟人数。重复准备演示数据可以增加新的有效到访次数，但参与腰牌数仍按腰牌去重；不清除既有记录，不把模拟数据写成实物来源。

## 验证

- 活动及统计测试15项通过，包含入口短时重扫合并、累计与去重的差别、同腰牌排序后计算间隔、跨腰牌隔离、同时间零秒、无样本为空、不可靠及未来时间排除、来源及会话隔离。日志：`logs/visit-summary-backend-test.log`。
- 网页类型检查、生产构建通过。构建日志：`logs/visit-summary-web-build.log`。
- 隔离服务的网页代理8项与设备控制8项检查通过。模型调用关闭，未影响正式进度。日志：`logs/web-gateway-test.log`、`logs/web-control-test.log`。
- 按项目启停脚本部署后，专用浏览器实际加载正式看板，读取同源活动响应并与展示值逐项核对。实物来源与切换后生成模拟来源均一致；后者进度为空。证据：`logs/visit-summary-browser-physical.json`、`logs/visit-summary-browser-generated.json`。
- 本次检查时生成模拟来源累计30次、参与10枚，节点累计18／9／3次；间隔20对、平均889.8秒。它们来自已保留的演示批次，不是现场游客观测，不是实际停留时长；后续新增记录会改变数值。

## 边界

本次不更新K230程序、不改腰牌固件、不清除收藏，不执行用户取消的长时间实机测试。只补累计汇总与间隔展示，尚不能据此宣称PRD全量完成。
