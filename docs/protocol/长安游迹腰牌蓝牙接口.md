# 长安游迹腰牌蓝牙接口

手机主链路采用蓝牙低功耗（Bluetooth Low Energy, BLE），与参考固件的素材传输共用 NimBLE 协议栈。服务不再等待 Wi-Fi 连接成功，未联网时也可建立本地连接。当前新增功能只允许读取身份和进度；签名解锁及可信后台确认仍在下一阶段实现，不提供绕过授权的解锁命令。

## 当前服务

新增服务使用通用属性配置文件（Generic Attribute Profile, GATT）：

| 对象 | UUID | 能力 |
|---|---|---|
| 活动服务 | `5e994001-64aa-4a10-b1f1-78ce02b3974f` | 主服务 |
| 实物身份 | `5e994002-64aa-4a10-b1f1-78ce02b3974f` | 只读 UTF-8 文本 |
| 本地进度 | `5e994003-64aa-4a10-b1f1-78ce02b3974f` | 只读 JSON |

稳定设备标识采用 `esp32s3-` 加 Wi-Fi 出厂 MAC 的十二位小写十六进制字符。它不等于浏览器生成的蓝牙设备编号，不因重新连接改变。手机必须读取该特征并与腰牌登记比较，不能只按广播名称判断。

广播仍保留原名称 `DOIT_TT` 和素材服务 `6e400001-b5a3-f393-e0a9-e50e24dcca9e`。Web Bluetooth 选择设备时可按原素材服务过滤，并把新活动服务放入 `optionalServices`；新服务不必单独放入容量受限的广播数据。安卓浏览器需要支持 Web Bluetooth，页面需要 HTTPS。手机浏览器可用性仍待实测。

进度示例：

```json
{"v":1,"device_id":"esp32s3-001122334455","session_id":"demo-001","game_id":"qin_formation","unlocked":false,"completed":false,"collected":false,"exhibiting":false}
```

进度读取返回同一个本地存储模块的状态，不修改解锁、游戏或收藏。存储未就绪或损坏时读取失败，不能返回伪造的初始状态。后台不得把未签名的工作人员输入当作设备执行证据。

## 验证边界

本阶段以完整固件构建验证编译和链接；未烧录、未进行手机连接和实机读取，不据此宣称跨端闭环完成。下一阶段将加入后台授权、设备认证响应与防回退同步，再开展烧录及设备联调。

接口设计参考 [Chrome 官方 Web Bluetooth 文档](https://developer.chrome.com/docs/capabilities/bluetooth)，包括 HTTPS、用户主动触发设备选择及 `optionalServices` 的要求。GATT 服务注册采用当前 ESP-IDF 内置 NimBLE 的 `ble_gatts_count_cfg`、`ble_gatts_add_svcs`，以本地 SDK 的头文件和构建结果核验。
