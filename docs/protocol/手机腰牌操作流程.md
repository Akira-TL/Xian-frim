# 手机腰牌操作流程

## 演示前提

演示免登录，内部后台令牌不由用户输入。准备已登记腰牌、后台设备私有配置和景区终端按契约提交的实物到访；手机打开可信 HTTPS 地址。当前网页代码已接入，安卓实物流程仍待验收。

## 操作顺序

1. 刷新到访，选择对应腰牌。页面显示编号、地点、时间、来源与请求状态。切换目标会断开旧连接并清理旧待发操作；操作进行中禁止切换。
2. 点击“连接并核对身份”，浏览器按原素材服务过滤设备，并授权访问新增活动服务。不以 `DOIT_TT` 名称或浏览器设备编号代替出厂身份。
3. 连接后读取实物身份，与登记严格匹配；不同则拒绝任何设备消息写入。匹配后生成只读挑战、写入 19 字节查询、读取 122 字节回执，由后台认证后同步进度，不自动解锁。
4. 只有当前腰牌、`demo-001`、A 点实物来源的到访可以解锁。未连接、未同步、身份不符、生成模拟、其他地点、已解锁或已过期请求，界面禁用解锁。
5. 点击解锁，后台创建或返回该到访的原请求；读取 16 字节设备随机数，取得后台授权，将完整 137 字节请求一次带响应写入，不能拆成多次独立写入。
6. 写入接受后记录 `sent`，仍不表示设备执行。随后读取原始认证回执并转交后台；身份、挑战和认证校验成功，且设备确认解锁，才显示成功并更新后台。
7. 孩子在腰牌点击开始。手机离线不影响已解锁游戏本地完成和收藏。下次连接或点击“认证同步进度”读取完成、收藏、展示及最近认证时间。

普通进度查询不把旧请求更新为已确认。若设备当前已解锁而旧请求尚未确认，分别保留“当前认证进度”和“旧请求状态”，不能手工补填成功。

## 超时与重试

设备选择由用户操作；选择后的服务连接与每次认证操作各有十五秒超时。故障、断线或超时使本次连接失效，晚到结果不能继续记录发送或提交设备确认。页面提示结果未确认，必须重新连接、先认证查询，再根据当前状态决定是否需要发送。一个连接内操作串行；不能并发查询与解锁替换回执。

后台授权挑战与设备随机数仍各有三十秒有效期，请求原有效期为五分钟，不因页面重试延长。过期且设备仍未解锁时，需新的实物到访；不能用生成模拟替代。列表刷新失败不推翻已经取得的合法设备回执，页面另行提示刷新问题。

## 已有证据与未验证部分

自动化使用真实本机后台、公开网页接口和外部设备替身，覆盖解锁认证、错身份零写入、模拟来源拒绝、连接先同步、发送与执行分离、晚到超时拒绝及并发操作拒绝。真实桌面浏览器已检查登记、刷新、模拟来源标注与禁用按钮。

尚未验证安卓 BLE 服务连接、完整长写入、实物回执、手机断线恢复、触摸通关与重启持久化。设备替身生成的测试认证码不能作为真实腰牌执行证据。
