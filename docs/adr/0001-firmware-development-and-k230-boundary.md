# 直接开发腰牌固件，K230 只定义接口

2026 年 10 月 2 日，用户确认设备固件已有备份，允许直接基于参考源码修改固件，无需再次备份。此决定覆盖 PRD 2.0 中“不修改固件”和“只通过原工具上传游戏脚本”的限制：首版采用原生固件实现触摸游戏、本地进度和设备控制，不再依赖尚未证实存在的脚本运行时。

当前开发范围包含腰牌固件、工作人员网页、后台和电脑看板；K230 的扫码、七英寸界面、驱动、部署与实机检查由其他开发方承担，本仓库只维护其到访上报和地图查询接口。首轮优先完成一个小游戏闭环，后台在开发电脑运行并采用 SQLite，手机通过 HTTPS 地址访问；其余目标沿用 PRD 2.0。

2026年10月3日，用户明确“外壳不要你建模”。外壳建模从当前 Agent 的交付职责移除，不再索要尺寸、不以模型缺失阻塞本项目收尾，也不宣称外壳已制作或装配通过。二维码身份契约和软件接口仍由本项目维护；实物位置、打印与装配不通过软件截图推断。
