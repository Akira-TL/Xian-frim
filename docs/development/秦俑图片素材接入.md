# 秦俑图片素材接入

用户已允许使用 `imagegen` 生成所需图片，也可以后续提供自己的素材。第一版游戏示意图已接入、压缩并烧录；空卡片修复后用户确认正常使用，详见[修复记录](../validation/秦俑空卡片绘制修复记录.md)。不代表真实文物复原或全部视觉与触摸指标定量验收。当前来源、尺寸、版本摘要和替换边界见[比赛素材清单](比赛素材清单与替换说明.md)。

## 图片放置位置

将图片放入项目的 `assets/qin/`，使用以下固定文件名。已有文件需要替换时保留自己的原图，构建脚本不会改写 PNG。

| 文件 | 用途 | 建议像素尺寸 |
|---|---|---|
| `head.png` | 头部碎片及对应轮廓 | 72×46 |
| `body.png` | 身体碎片及对应轮廓 | 72×46 |
| `legs.png` | 腿部碎片及对应轮廓 | 72×46 |
| `reward.png` | 收藏与展示的完整图片 | 200×160 |

推荐透明背景 PNG；三片从同一张图按上下顺序拆分，画布宽度保持一致，便于吸附后组成完整形象。游戏卡片仍为72×54，轮廓为72×46。图片按比例适配，不拉伸；碎片及轮廓使用同一份素材，轮廓整体半透明显示。缺少某张图片时仅该位置保留占位图，不能凭有图片就提前解锁奖励。

奖励图片区域为圆屏中央的200×160，不能直接使用360×360满屏图并假定文字、首页按钮不会遮挡。若需要更大展示区域，应另行调整页面布局，不改变此入口的状态语义。

## 构建与烧录

```sh
source /home/Akira/github/esp-idf/export.sh
bash tools/build.sh
bash scripts/device.sh flash /dev/ttyACM0
```

`tools/build.sh` 自动调用 `scripts/assets/prepare-qin-assets.sh`，通过 uv 的 `assets` 依赖组使用仓库现有 LVGL 9.3 官方 `LVGLImage.py` 转换器，将 PNG 转为带透明通道的 ARGB8888 C 数据，并使用游程编码（Run-Length Encoding, RLE）无损压缩。仓库默认配置同时启用 `CONFIG_LV_USE_RLE=y` 和 `CONFIG_LV_BIN_DECODER_RAM_LOAD=y`，运行时由 LVGL 内置解码器加载并解压。仅启用 RLE 不能绘制压缩图片，已经在真实绘制测试中复现空卡片。原图不变，不依赖运行时 SD 卡、联网或额外 PNG 解码器。

已有构建目录的 `sdkconfig` 不会自动用新默认值覆盖旧选项，必须确认上述两个开关均启用后重新配置，或者通过 `BUILD_DIR` 使用新的构建目录。不能只生成压缩图片却使用未启用完整解码路径的旧固件。构建后通过 `bash scripts/test-qin-render.sh` 检查真实图片入口是否产生可见像素；测试从实际构建目录读取两个解码选项，不能用硬编码正确配置掩盖遗漏。压缩降低闪存占用，解码后的像素缓冲仍占内存；奖励图最大128000字节，不能将压缩比例当作同等内存节省。

生成文件仅位于 `build/qin-assets/`，不手工编辑，不提交。删除输入 PNG 后再次构建，对应生成文件会更新为空占位声明，避免继续嵌入旧图。非默认构建目录通过 `BUILD_DIR` 传给 `tools/build.sh`；`QIN_ASSET_SOURCE_DIR` 可临时指定素材目录，主要用于隔离验证，不改动正式的 `assets/qin/`。

建议按上述尺寸导出。超大原图会增加固件体积；完整构建的分区大小检查失败时不得强行烧录。图片修改之后必须重新执行 `tools/build.sh`，不能只运行烧录命令。更新图片与固件不会主动清空游戏 NVS 进度；已收藏的奖励可更换显示内容，但仍属于原来的唯一奖励。

每张图片的生成来源、版本摘要和文化表述边界已集中记录在[比赛素材清单](比赛素材清单与替换说明.md)。新增图片或文化文字时继续更新对应来源，不把生成图称为考古复原或真实文物照片。

2026年10月3日，使用内置图片生成工具取得第一版完整人物参考图，保存为 `assets/qin/source/terracotta-warrior-v1.png`。用户明确同意从同一图精确裁剪、缩小后，四个正式 PNG 入口已导出。随后按用户要求压缩固件图片数据：嵌入图片从167744字节降至61498字节，减少63.34%；应用分区余量36%。三片可逐像素拼回统一缩小图，压缩后经 LVGL 原生解码与 PNG 独立像素比较完全一致。不宣称实际圆屏视觉验收通过。完整提示词、导出参数和使用边界见[秦俑生成素材记录](秦俑生成素材记录.md)。
