# 圆屏展示界面优化

本轮只优化360×360圆屏的软件展示，不连接、烧录、重启或控制实物，不改变路线推荐和网页数据。

## 视觉与交互

- 封面复用本轮网页的长安水彩插画，标题与辅助语置于上部留白，主入口使用墨绿按钮，保留收藏和设置入口。
- 游戏选择和开始页采用金线插画卡框、较大主按钮和紧凑辅助操作；三个游戏仍通过左右滑动切换，当前游戏以朱砂短线标记。
- 游玩页面保留三片拼图和寻宝热点的原有尺寸、位置及素材，只统一按钮表面，避免视觉更新破坏已验证的操作。
- 成功页使用对应奖励图片；收藏及展示继续反映原有游戏进度，不生成虚假收藏。

## 素材来源与尺寸

封面源为 `assets/web-display-v1/explore-hero.png`，由上一轮内置 imagegen 生成；完整提示词见 `三页网页展示视觉稿与素材提示词.md`。本轮复用该素材，没有重新生成或改画图片。

运行 `node scripts/assets/prepare-badge-display.ts`，将封面缩小到360×360并量化为128色，输出 `assets/qin/cover.png`。正式固件仍由既有LVGL图片转换管线生成有界、游程编码压缩素材，不嵌入原始高分辨率插画。

## 软件验收

通过 `scripts/test-qin-render.sh` 运行真实LVGL绘制入口与游戏页面回归，检查图片可见、坏图降级、秦俑拖拽、三个游戏左右切换、寻宝答题、诗句答题、设置返回保留进度与独立收藏展示。

实际页面绘制缓冲保存在 `logs/badge-display-v1-preview/`；`overview.png` 上排为封面、游戏选择、秦俑游玩，下排为收藏、城门选择、诗句游玩。它是正式页面的软件绘制预览，不是实物照片。

生成预览时应单独运行 `qin_page_test`，不要使用最后运行的坏图回归截图覆盖正常素材预览：

```sh
mkdir -p logs/badge-display-v1-preview
QIN_PREVIEW_DIR="$PWD/logs/badge-display-v1-preview" build/qin-render-test/qin_page_test
node scripts/assets/preview-badge-display.ts
```

实物烧录与触摸验收由用户处理，本轮未执行。
