# 演示节点配置

`GET /api/v1/sites` 供工作人员或终端读取强类型演示园区配置。无凭据访问后台返回 `401`；网页免登录代理是否开放由其白名单控制，不取消后台权限。

网页同源代理已开放该路径的只读免登录查询，客户端验证完整节点、示意地图属性、可达关系与未实现小游戏标记；不开放节点配置写入。

配置来源固定为 `demo_site_configuration`，`geographic_map=false`。A 秦俑工坊、B 长安城门、C 诗意庭院沿用 PRD 2.0。`x`、`y` 是0—1的示意坐标，没有真实距离、旅行时间或安全容量含义。

节点包含 `is_open`、有向 `reachable_sites`、任务名、内容提示、`game_id` 和 `game_available`。默认三点均开放且两两可达，这是演示园区假设，不是现场开放或道路事实。节点配置和可达关系由后台持有，推荐请求不能自行提交或覆盖。

当前v5已经接入三款实际游戏，默认 `game_available=true`：A为 `qin_formation`，B为 `gate_search`，C为 `poem_completion`。B/C属于用户追加的本地演示游玩，不代表扫码解锁或认证到访；节点配置提示明确该边界。

可通过 `CHANGAN_SITE_CATALOG_PATH` 指定项目本地 JSON 配置，格式为该接口返回格式。未设置时采用内置演示配置。配置须包括 A/B/C 各一次，不能包含未知字段、自可达或重复可达项，不能把未实现的扩展小游戏标为可用；启动时验证，错误配置不静默降级。重启服务才载入新配置，本阶段没有管理员在线修改接口，也没有操作 K230 程序。

`tests/backend/test_catalog.py` 通过公开接口检查 PRD 名称、示意地图属性、小游戏标记与后台读权限。网页原有 B/C 名称已修正，与本配置一致。

## 管理员配置演示热度阈值

节点配置增加 `heat_thresholds`，包含中热度起点 `medium_min` 和高热度起点 `high_min`。省略时采用 PRD 示例值3、6，即低0—2、中3—5、高6及以上。自定义时必须为整数，不能用布尔值或数字字符串；中热度起点至少1，高热度起点必须更大。两值上限均为2147483647，作为配置整数范围限制，不是场地容量上限。

管理员可从免登录网页的 `/api/v1/sites` 取得完整配置，保存为项目 `data/site-catalog.json`，调整以下部分，同时递增 `version`：

```json
"version": 2,
"heat_thresholds": {"medium_min": 1, "high_min": 2}
```

这是完整配置中的片段，不是可独立启动的文件。保留 A/B/C 的全部节点字段，通过项目脚本加载：

```bash
CHANGAN_SITE_CATALOG_PATH=/home/Akira/Projects/Xian-frim/data/site-catalog.json bash scripts/demo.sh start
```

配置只在启动时加载；先正常停止本次后台和网页，再按上述入口重启，不直接终止其他服务。没有在线编辑接口，不因演示免登录而开放后台配置写入。

地图和活动快照回传所用阈值，看板图例读取该快照而非使用前端常量；推荐输入也保存同一阈值及节点配置版本。调整配置只改变热度分类，不改写到访、去重计数、进度或既有推荐历史。数据缺失、不可靠或过期时仍显示“数据不足”，不会因低阈值成为高热度或低热度。

已有历史快照没有该字段时采用旧固定阈值3、6，不套用新配置。所有阈值仍是“演示阈值”，不能用于判断现场安全容量或实际在场人数。K230 只涉及接口新增字段，本项目不操作其程序。
