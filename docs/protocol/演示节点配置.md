# 演示节点配置

`GET /api/v1/sites` 供工作人员或终端读取强类型演示园区配置。无凭据访问后台返回 `401`；网页免登录代理是否开放由其白名单控制，不取消后台权限。

配置来源固定为 `demo_site_configuration`，`geographic_map=false`。A 秦俑工坊、B 长安城门、C 诗意庭院沿用 PRD 2.0。`x`、`y` 是0—1的示意坐标，没有真实距离、旅行时间或安全容量含义。

节点包含 `is_open`、有向 `reachable_sites`、任务名、内容提示、`game_id` 和 `game_available`。默认三点均开放且两两可达，这是演示园区假设，不是现场开放或道路事实。节点配置和可达关系由后台持有，推荐请求不能自行提交或覆盖。

首版只有 A 点 `qin_formation` 小游戏已经接入。B/C 只是《城门寻宝》《诗句补全》的地图与内容配置，`game_available=false`，提示明确触摸小游戏尚未接入；推荐不得声称这些小游戏已可玩。

可通过 `CHANGAN_SITE_CATALOG_PATH` 指定项目本地 JSON 配置，格式为该接口返回格式。未设置时采用内置演示配置。配置须包括 A/B/C 各一次，不能包含未知字段、自可达或重复可达项，不能把未实现的扩展小游戏标为可用；启动时验证，错误配置不静默降级。重启服务才载入新配置，本阶段没有管理员在线修改接口，也没有操作 K230 程序。

`tests/backend/test_catalog.py` 通过公开接口检查 PRD 名称、示意地图属性、小游戏标记与后台读权限。网页原有 B/C 名称已修正，与本配置一致。
