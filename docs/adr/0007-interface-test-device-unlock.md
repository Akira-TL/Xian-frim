# 接口测试记录与真实腰牌联调

## 决定

用户已明确允许测试打卡及真实腰牌解锁联调，并授权通过 ADB 操作手机项目网页，不再要求用户代点。

新增 `interface_test` 来源及 `/api/v1/interface-test/visits`。它只用于固定会话 `demo-001`、A 点和专用标识 `interface-test-001`，不冒充 K230，不开发或操作 K230。

接口测试记录可以解锁对应实物腰牌，但必须沿用身份核对、后台授权、设备随机数、认证回执和幂等控制。生成模拟来源仍不能控制实物。

真实扫码统计和真实到访进度汇总只使用原有真实来源，不计接口测试记录。测试来源单独查询时只展示测试统计，不混入真实进度汇总。推荐仍按来源隔离，接口测试推荐不使用真实到访认证完成记录。

手机端仍为免登录网页，不安装应用。测试按钮和记录须明显标注，不执行清除腰牌进度或擦除存储操作。

接口测试不是手机离线采集的扫码事实，其记录时间由后台首次接收时产生并标为 `synced`，不采信手机时钟。原始请求仍参与编号冲突校验；相同请求重试不得刷新首次记录的时间，旧记录不追溯改写。真实扫码和生成模拟的时间规则保持不变。

## 验证

使用已确认的公开 HTTP 接口测试边界，内部业务及 SQLite 使用真实实现；蓝牙先通过既有边界替身验证，手机 ADB 实机操作另留证据。验证测试来源可授权、身份不符拒绝、生成模拟仍拒绝、重试幂等、终端身份不能伪装以及真实统计隔离。
