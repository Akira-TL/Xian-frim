# 手机腰牌操作流程

2026年10月3日当前版本：免登录网页、三游戏v5、独立个性化路线。无需安装应用或输入服务端令牌；安卓浏览器须支持 Web Bluetooth，页面使用 `https://babelbeast.com/xks`。最新用户决定取消出厂地址比对，不取消真实设备回执。

## 腰牌连接与游玩

1. 探索页选择001号，点击“连接腰牌”，在浏览器选择 `DOIT_TT`。广播名不是授权凭据，页面仍读取协议字段并进行查询挑战和回执验证。
2. v5使用包内001逻辑编号，允许同硬件远端烧录，不按各芯片出厂地址拒绝；共享编号不是多枚独立游客。旧v4须升级，不能只改网页提示。
3. 连接先做只读认证同步，不解锁。签名回执通过后显示秦俑进度，实时轮询显示当前封面／游戏／阶段与新增游戏收藏；实时遥测与认证统计分开，断开清除实时状态。
4. 秦俑尚未解锁时，须有A点有效实物到访或明确接口测试记录。无现场扫码，可在“演示解锁”创建A点测试打卡，之后点击“解锁秦俑归阵（演示）”。测试记录不计真实扫码，生成模拟不能控制实物。
5. 解锁沿用后台请求、16字节设备随机数、137字节完整带响应写入与122字节回执。写入成功只记录发送，后台验证原始回执后才确认执行；超时或假回执不变成成功。
6. 腰牌开始、游戏选择页左右切换。秦俑拖三片；城门按提示找门、旗、鼓；诗句两道触摸选择。后两款本地演示无需到访解锁，但也不产生认证到访。
7. 设置、返回或换游戏保留本次进度；只有主动重玩／重开才清本次拼图。收藏和展示持久化，复玩不重复增加。新增游戏阶段保留于运行内存，不宣称断电保存。

## 路线与活动概览

底部“路线”直接进入指引，无腰牌区块、不要求连接或扫码。主动选择同行、兴趣、节奏、出发点后，模型综合候选热度和配置推荐；默认明确为演示热度，不称实时人数。“换个推荐”有其他有效候选时避开上一条；修改偏好或出发点按新条件重算。

“就去这里／暂不去”只记选择，不新增到访、解锁或完成。最近八次图文建议、时间、当次依据和选择保存当前浏览器，刷新与切页恢复，不跨设备。旧建议热度过期仍可回看，不当作当前客流、不再接受为当前选择。模型失败明确规则或无建议，历史不冒充新AI请求。

探索页“活动概览”单独展示A/B/C热度、更新时间、活动累计和参与腰牌；来源切换不改变腰牌连接及游戏目标。缺失、过期或时间不可靠显示数据不足，观测数不等于实时在场人数。完整趋势和推演在电脑看板。

## 失败与证据

设备选择后的建链与认证有超时；错误、断线或超时使连接失效，晚到结果不更新状态。重连先认证查询，不清游戏数据，不把刷新恢复说成已消除历史偶发蓝牙失败。

设备随机数和查询挑战三十秒有效，请求五分钟有效，不因重试延长。既有回执只说明认证时状态，不证明设备一直在线。正式测试与当前实物证据见[三游戏与路线核查](../validation/三游戏与动态路线联动核查.md)、[交付说明](../development/比赛版交付说明.md)。设备替身不是实物首次解锁；用户取消的长测不重新安排。真实触摸录像和远端新包验收尚未取得。
