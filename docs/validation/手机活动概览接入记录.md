# 手机活动概览接入记录

## 缺口与修改

2026年10月3日核对PRD第12.1节发现：手机页面已有到访记录、单次处理、身份核对、认证进度及下一站建议，但活动概览只能通过链接跳转电脑看板。现将三节点紧凑概览直接接入 `https://babelbeast.com/xks`，不修改腰牌控制逻辑。

概览显示各节点近五分钟不同腰牌数、热度、观测更新时间、演示阈值，以及当前会话累计到访和参与腰牌。支持实物扫码／模拟地点、接口联调测试和生成模拟三种来源独立切换；切换时不展示其他来源残留数字。读取失败显示旧快照与当前未确认，地图卡片变灰。概览只读，不产生到访、不改变所选腰牌、不自动连接设备或调用模型。

下一站建议继续关联下方明确选定的到访事件：页面提示选择记录后生成、查看依据和拒绝，不把概览来源切换当作推荐事件选择。原后台、设备连接、执行三项状态及认证进度保留。

## 快速证据

- 网页类型检查与生产构建通过，日志：`logs/mobile-overview-web-build.log`。
- 使用项目启停脚本发布后，实际专用浏览器加载正式手机网页；默认实物来源三个节点无记录，均显示数据不足。
- 实际切换到生成模拟来源，逐节点比对同源活动响应的计数和热度，并比对累计次数与参与数，均一致；已过期模拟观测显示数据不足，设备目标仍为空，没有因切换而选中另一枚腰牌。证据：`logs/mobile-overview-browser-generated.json`。
- 初次调用浏览器模拟尺寸未持续生效，未将其记作360像素检查通过。随后实际缩窄专用窗口，页面可用宽度485像素，概览453像素、卡片垂直排列且没有横向溢出；检查后恢复窗口原尺寸。证据：`logs/mobile-overview-browser-narrow.json`。这是浏览器窄屏布局检查，不是安卓实物蓝牙验收。
- 不改固件、不清进度、不操作K230、不要求用户执行已取消的长时间实机测试。

## 后续范围

手机核心处理和推荐已有实现，本次只补页内概览。外壳真实测量、真实操作录像和剩余交付物仍须单独核对，不能据此宣称全部PRD完成。
