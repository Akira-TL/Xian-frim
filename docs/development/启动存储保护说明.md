# 启动存储保护说明

## 目的和行为

《秦俑归阵》的进度保存在默认 NVS 分区的 `exploration` 命名空间中。原 `main/main.cc` 在初始化返回 `ESP_ERR_NVS_NO_FREE_PAGES` 或 `ESP_ERR_NVS_NEW_VERSION_FOUND` 时自动擦除整个分区；这并非只删除 Wi-Fi 配置，也可能删除收藏和游戏进度。

启动不再自动擦除或重试初始化。上述两类错误会记录错误名称和保留数据的提示，然后由已有 `ESP_ERROR_CHECK(ret)` 阻止应用继续启动。其他初始化错误继续由同一检查处理；初始化成功的路径不变。

这项保护优先保留已有数据，不承诺存储损坏后仍能启动或自动恢复。需要恢复时，应先诊断故障、确认可恢复的数据和具体范围，并取得删除数据的单独授权。用户允许修改和烧录固件，不等同于允许清空游戏进度。

## 验证边界

完整固件构建验证实际启动代码及其 ESP-IDF 错误常量、日志和链接；现有纯 C 测试验证游戏与授权业务没有回归。代码审查确认启动错误路径没有擦除调用。

未在实物上注入上述存储错误，不把静态检查称为错误注入测试。实物触摸后的收藏、展示及重启保持仍按[实机验收记录模板](../validation/实机验收记录模板.md)另行验收。
