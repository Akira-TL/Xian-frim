## 规范轴

无必修问题。只处理明确的 `asyncio.CancelledError`，不吞任意程序异常、不把取消当作服务不可用。沿用已存在的强类型拒绝记录与私有存储，不新增表或扩展匿名权限，也不引入通用抽象。

测试从公开 HTTP 应用接口取消请求任务，只以外部模型和时钟为替身；通过私有查询和公开历史查询观察记录，未查询数据库私有表或模拟内部业务类。测试同步事件来自外部模型替身，用于确定模型已开始以及晚到返回已完成，不用固定等待时间推测取消生效。

## 需求轴

本阶段无必修问题。服务端等待模型时观察到取消，保存完整输入及明确取消状态，没有原始返回时保持为空，并继续传递取消异常。模型晚到返回不改变记录，不生成有效建议历史或设备命令；拒绝记录跨后台重启保持。

测试是应用任务取消，不是实际安卓断网；浏览器断开并不保证服务端任务取消。数据库写入失败或进程被强制结束不能保证记录保存，契约明确限制，不宣称已验证断电恢复。真实模型调用与显示、实物链路和三十分钟验收仍缺。
