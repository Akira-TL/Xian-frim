## 已验证入口

- 后台：`uv sync` 安装，配置不同的工作人员/终端令牌后 `bash scripts/backend.sh` 启动；终端中断停止，日志为 `logs/backend.log`。隔离数据库的本地运行已验证健康接口和正常停止。
- 演示网页：用户确认默认免登录。`services/web/` 安装与构建后，根目录 `bash scripts/demo.sh dev|start` 自动建立本次运行的内部通信凭据并启动本机后台与网页；终端中断同时停止两者，隔离端口启停已验证。页面已提供到访、来源标注、登记、请求状态、蓝牙连接、授权及认证同步；四项公开 HTTP 与七项认证操作测试通过。专用桌面浏览器实际登记、刷新及选择模拟事件通过；发现并修复合法同源请求被框架回环地址归一化误拒绝的问题。安卓 BLE 实物链路尚未验收。
- 电脑看板：`bash scripts/demo.sh start` 后访问 `/dashboard`，免登录，每五秒查询活动快照。专用桌面浏览器检查空数据、来源切换、零分母及断线旧快照提示通过。当前节点是示意，趋势为窗口表；AI 与情景推演未填充虚构结果。运行说明见 [电脑看板运行](../development/电脑看板运行.md)。
- 情景推演：看板参数表单可计算独立假设方案，完整回传参数与生成时间可核对；全分流和半分流浏览器结果与手算一致。修改参数未计算时不改写旧曲线，失败移除结果，未新增到访。当前网页公开接口六项、认证操作七项通过。
- 推荐网页与后台：`POST /api/v1/recommendations` 从既有到访构造候选，未配置模型时只给明确规则建议；快照存入 SQLite，历史查询保留生成时间与过期标记。手机操作页及电脑看板已免登录接入生成、历史回读和仅本页的采纳／拒绝。专用桌面浏览器检查规则标记、历史来源、切换清除、断线暂停及人工选择不制造实物记录；八项公开接口与七项认证操作测试通过。当前尚未调用模型，不能当作 AI 验收证据。模型服务和凭据路径已询问用户。
- 后台测试：`uv run pytest -q`，目前七十二项通过，包含模型输出、等待时限、故障降级与私有审计、推荐候选／快照、节点配置、情景推演、活动快照、私有配置工具及工作人员登记／请求查询验证。本执行环境内测试客户端在沙箱中停于事件循环唤醒，同一组测试在沙箱外通过，具体差异已检查线程堆栈。
- 固件：加载本地 ESP-IDF 环境后 `bash tools/build.sh`；新增源文件或私有头文件后需重新配置构建。ESP-IDF 5.4.1 完整构建通过，最新日志为 `logs/firmware-page-startup-build.log`。
- 游戏与认证核心测试：`bash scripts/test-firmware.sh`，覆盖锁定、错误恢复、三片通关、收藏、复玩，以及错误身份、认证、过期、存储失败和幂等重试。
- 设备：`bash scripts/device.sh inspect|flash|monitor /dev/ttyACM0`。沙箱隐藏串口节点，获准设备访问后检查与烧录正常。私有配置通过 `bash scripts/provision-device.sh <实物身份>` 生成，位于被忽略的 `data/`。
- 启动回归：二十五秒及六十秒检查均在实机通过。原配网内存不足、字体初始化缺失和页面回调缺失分别修复；该检查不证明完整游戏流程通过。用户澄清不是缺字，而是字号小；页面已改用统一字体并放大至约二十七像素，仍待用户核验可读性。

本轮已烧录 ESP32-S3 固件，未整片擦除，也未操作 K230；原始参考压缩包仍保留且未纳入本轮提交。固件包含私有密钥，不得公开分发二进制。

## 下一段实现

可信 HTTPS 手机入口仍需解决；临时公网隧道尚未得到明确许可，不启动或擅自公开免登录服务。安卓实机需要完成设备核对、授权写入、真实回执、触摸与本地重启保持。看板、情景推演、推荐快照／网页、模型输出校验、时限、故障降级和成功建议私有审计已交付，后续继续真实模型服务接入和过期／取消尝试审计，并逐项进行实机及持续展示验收。后台不得通过工作人员手工布尔值宣称设备已执行，不得从模拟到访向实物发出命令。
