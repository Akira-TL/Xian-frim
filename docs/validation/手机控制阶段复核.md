## Spec

免登录贯穿客户端操作，不增加账号或浏览器凭据输入。身份匹配检查在所有设备写入之前，模拟、错腰牌或非 A 点到访不能解锁；新连接先认证进度。写入接受只记录已发送，合法回执认证才确认执行。错误、超时和断线需重连后先查询；进度来自后台认证，不接受人工布尔值。

浏览器使用已证实的服务 UUID 和带响应完整写入；是否可在目标安卓设备完成 137 字节长写入仍需实际连接证明，不能用类型检查推定。

真实桌面浏览器发现合法 `Origin: http://127.0.0.1:<端口>` 被拒绝，`localhost` 却通过。公开 HTTP 同源回归先返回 403 而失败；修正使用实际 Host 后，同源登记通过，外站来源仍返回 403。原浏览器登记再次实际成功。原因是框架内部回环 URL 归一化，不是用户登录或设备权限问题。

完整产品仍缺安卓实机授权、真实回执、可信手机 HTTPS 入口、奖励重启保持、持续验收及其他看板/AI/推演工作。本阶段未填补或降级这些要求。
