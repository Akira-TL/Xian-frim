# 免登录演示网页阶段复核

## 复核材料

2026 年 10 月 3 日，按 PRD 2.0 第 6.4、12.1、12.2 节、ADR 0001、ADR 0003 与用户“默认所有人都可以用，调试也这么设置”的决定实现网页阶段。

固定差异为 `git diff abe95e8...7f72634`，提交顺序：

1. `27676b9`：类型化网页基础、修补依赖、运行入口。
2. `bdcd7d9`：网页入口直接监督 Next.js 进程，避免多层启动器带来的停止边界不明确。
3. `9749e1c`：免登录服务端转交、路径限制、公开 HTTP 契约测试。
4. `0be5292`：到访列表、来源与请求状态展示、不可覆盖的腰牌登记。
5. `7f72634`：双服务默认启动、临时内部凭据与停止联动。

使用当前 Agent 的非隔离双轴顺序复核，不宣称独立 Agent 验收。两个轴依据相同固定差异与上述材料。

## Standards

依据用户工程规则、`CONTRIBUTING.md` 与 code-review 代码坏味道检查：业务代码为严格 TypeScript，不使用 `any` 或未结构化字典；接口响应在使用前经 Zod 校验。PostCSS 配置采用其加载器支持的 JavaScript 模块，其余配置为 TypeScript 或 JSON。操作与停止通过项目脚本，日志在被忽略的 `logs/`；没有提交真实数据库、内部令牌、设备密钥或构建文件。

Next.js 15.4.11 安装审计存在严重告警，首次建立采用 15.5.27，并固定存在间接依赖告警的 PostCSS 与 sharp 修补版本；生产依赖审计现为零告警。不能把旧安全公告中的修补版本当作长期安全保证，也没有对已有网页进行无关迁移。

运行入口修正已独立提交。页面网络查询与登记表单错误分开：输入错误不会把后台误报为离线，状态文字说明只是最近查询结果。未发现剩余规范违反或需处理的代码坏味道。脚本目录规模建议因既有文件数量触发，新增入口职责明确，使用 Guard 显式确认；未将其他文件机械迁移。

## Spec

用户免登录决定已覆盖原工作人员登录设想；浏览器不填写通信令牌，默认启动由服务端生成临时凭据。没有因免登录取消登记身份、到访来源或设备认证约束；终端实物上报路径仍只在后台终端契约中可用，不对公开网页转交。

到访显示腰牌编号、地点、采集时间、来源、时间不可靠标记和请求状态；已发送与设备确认分开。页面没有任何人工“已执行”按钮，模拟到访不变成实物到访。当前阶段尚无蓝牙写入，页面明确标注未连接与未核验，不应被误认为 PRD 手机流程已全部完成。

未发现本阶段范围内的错误实现或无关扩展。完整目标仍有实物身份读取、授权/回执、可信 HTTPS、安卓浏览器、进度与收藏重启、看板、AI、情景推演和持续验收等缺口。

## 证据

- `npm run build` 完整构建通过，`npm run typecheck` 通过；最新细小状态文字修正也经类型检查，不据此推定浏览器视觉已验证。
- `npm audit --omit=dev --audit-level=high` 返回零告警。
- 新公开查询测试先因接口不存在返回 404 而失败；登记测试先因没有 POST 返回 405 而失败。实现后四项真实 HTTP 测试通过，日志为 `logs/web-gateway-test.log`。
- 隔离测试使用临时数据库、专用内部测试令牌，不加载实物设备密钥。测试结束后 8123、3101 端口无监听。
- 默认双服务入口以单独测试数据库与 8124、3102 端口实测，不输入浏览器令牌即可返回登记列表；网页原始 HTML 有免登录、到访、登记和设备未连接提示。Ctrl+C 后两个监听均消失。
- 尚无真实浏览器视觉/触摸、安卓 BLE 或 HTTPS 访问证据；服务返回 HTML 不能替代这些证据。

Standards：无剩余发现。Spec：本阶段无发现，完整产品仍有上述未完成部分。下一阶段应接入并验证真实设备控制，而非扩大免登录接口去伪造到访或设备成功。
