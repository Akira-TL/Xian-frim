# 手机传图与自定义封面

## 使用方式

在网页“探索”页的“我的腰牌”内点“传图”，选择手机照片。选图不需要先连接腰牌；圆形预览展开在原位置，不跳转到另一页。

拖动照片调整位置，用缩放滑条调整大小。网页自动裁剪为 360×360 并压缩，显示压缩后的大小，最大 48KB。处理在浏览器本地完成，照片不上传到模型服务或后台。

尚未连接时，点“先连接腰牌”选择设备；连接完成后点“设为腰牌封面”。无需编号、登记、扫码或身份校验。浏览器自身的设备选择框仍需用户选择，这是浏览器连接设备的必要交互，并不是项目的额外权限门槛。

上传时显示设备确认的接收进度，可以取消；最后显示“正在保存封面”，只有设备成功保存并确认版本后才显示成功。保存期间暂时禁用离开页面的按钮，避免误操作丢掉结果提示。异常会退出等待并允许重试，不把传完字节当作成功。

封面只影响游戏入口背景，文字和开始、收藏、设置入口仍可用。三个游戏、拼图进度、游戏收藏与路线记录均不改变。新图未完成保存不会擦除旧图；封面重启后仍保留。“恢复默认封面”提供就地确认并等待设备保存，不恢复原固件图片浏览器。

## 版本要求与限制

必须使用带 `cover` 分区和传图蓝牙特征的新固件。旧固件仍可连接和同步游戏状态，但点传图保存时会明确提示更新固件，不冒充支持传图。

原始图片最大 25MB。不能被浏览器解码的图片、过于特殊的比例、无法输出 JPEG 或压缩后仍超限的图片会显示提示。吧唧再次核验 JPEG 格式、完整性和 360×360 尺寸。无存储卡时也可使用。

## 当前软件验证证据

- 网页类型检查、正式构建以及 `bash scripts/tests/test-cover-web.sh` 的具名断言覆盖裁剪、压缩上限、传输与失败处理。
- `bash scripts/test-qin-render.sh` 使用真实固件 JPEG 解码器和封面绘制函数，核验屏幕缓冲照片像素、持久化、恢复默认与失败保护，并保留三个游戏的交互回归。
- 电脑浏览器已验证真实选图、圆屏预览和缩放。项目示例图居中时约 13KB，放大后约 17KB；浏览器生成的 JPEG 已通过正式固件解码校验。
- 界面检查使用 390 像素宽展示容器；浏览器真实视口为 500 像素，不将该结果描述为手机实机截图。

软件验证不替代真实手机蓝牙、圆屏、断电和触摸验收。本功能开发不执行实物连接、烧录、重启或手机物理操作，均由用户负责。
