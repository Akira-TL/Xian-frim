# 免登录演示网页接口

用户确认演示参与者无需登录，调试也不输入工作人员令牌。浏览器访问网页自身的 `/xks/api/v1/`；Next.js 服务端用 `CHANGAN_OPERATOR_TOKEN` 向本机后台请求，内部令牌不返回给浏览器。`CHANGAN_BACKEND_ORIGIN` 默认 `http://127.0.0.1:8000`，正式服务配置为本机8040；不可含凭据、路径、查询或片段。

## 开放范围

- 查询：登记列表、到访列表、解锁请求列表、地图、演示节点配置、看板活动快照、指定腰牌已认证进度。
- 操作：登记腰牌、创建解锁请求、标记已发送、生成设备授权或查询挑战、提交原始认证回执。
- 演示调试：`POST /api/v1/demo/visits` 只产生 `generated_simulation` 来源，不能控制实物腰牌。
- 演示准备：`POST /api/v1/demo/prepare` 按批次创建10条虚拟记录；同批次重试不重复创建，不自动调用模型或控制设备。
- 实物联调：`POST /api/v1/interface-test/visits` 仅创建A点专用接口测试记录，不冒充K230，不计真实扫码；解锁仍需身份核对、后台授权及真实认证回执。
- 假设计算：`POST /api/v1/simulation` 返回独立情景推演，不写入活动记录；所有演示参与者均可调用。
- 建议：`POST /api/v1/recommendations` 和 `GET /api/v1/recommendations/{snapshot_id}`；只生成受后台候选约束的建议或历史回读，不自动解锁。
- 不开放：终端实物到访上报、终端心跳及地点配置接口、任意其他后台路径。免登录不赋予景区终端身份。

身份匹配、到访来源和设备认证均由既有后台契约校验，免登录不取消它们。伪造布尔值不能变成设备进度，未配置密钥返回 503，未取得合法回执的进度查询返回 404。

## 请求与错误

写入要求 JSON，请求上限 16 KiB。只向固定后台地址转交允许的方法和路径，不接受浏览器的访问令牌作为代理身份，不跟随后台重定向。未知路径返回 404；跨站写入返回 403；大小超过限制返回 413；非 JSON 返回 415。后台响应保留状态码与内容类型，设置 `Cache-Control: no-store`，不复制后台身份凭据或 Cookie。后台超时／不可达返回 502，并明确结果未确认。

页面同源写入无需用户账户。反向代理使用 `CHANGAN_PUBLIC_ORIGIN=https://babelbeast.com` 核对浏览器 `Origin`；不要把手机入口设为手机自身的 `localhost`。正式域名已部署，安卓Chrome实际连接、身份核对及认证进度已有记录，见[三次主动重连](../validation/图片修复版三次主动重连记录.md)。内部网页进程仍只监听本机，不表示外部只能本机访问；这也不代表所有安卓浏览器均兼容或蓝牙长期稳定性通过。

## 隔离测试

先在 `services/web/` 执行 `npm ci` 和 `npm run build`，然后在根目录运行 `bash scripts/web/test-gateway.sh`。脚本使用固定测试端口 8123、3101、临时数据库和专用测试令牌，仅载入 `services/web/tests/fixtures/device-keys.test.json` 的公开测试夹具密钥，不载入实物设备密钥；结束停止它启动的服务，数据库在输出的 `/tmp/changan-gateway.*` 路径保留。公开接口日志为 `logs/web-gateway-test.log`，认证操作日志为 `logs/web-control-test.log`，另有网页和后台运行日志。夹具密钥严禁用于真实腰牌或生产后台。

公开 HTTP 八项测试覆盖免登录查询与登记、节点配置、建议与历史标记、活动快照及模拟来源边界、假设计算与事实隔离、合法浏览器同源 `Origin`、终端路径隔离、未认证进度、缺少对应设备密钥、伪造报告、跨站与请求大小限制。另有八项公开认证操作测试。该测试不替代手机BLE连接、真实设备回执或外部模型证据；模拟准备入口另有[实际点击记录](../validation/比赛演示数据入口记录.md)。完整职责和路径索引见[系统职责与接口索引](../development/系统职责与接口索引.md)。
