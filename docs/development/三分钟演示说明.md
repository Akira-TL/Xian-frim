# 三分钟演示说明

这是准备执行的演示路径，不是完整验收的记录。真实 DeepSeek 请求、可信 HTTPS 手机连接、实物认证解锁、旧版用户本地通关收藏及展示、新固件更新后四项状态保持已有证据；新版拖拽手感、实物三轮／三十分钟和备用实物录像仍未验收，不能宣称完成首版演示。当前证据以 [首版实现状态](../product/首版实现状态.md) 为准。

## 演示前准备

正式演示使用已部署服务：从项目根目录运行 `bash scripts/domain-demo.sh status` 检查；停止时可用 `bash scripts/domain-demo.sh start` 启动。电脑打开 `https://babelbeast.com/xks/dashboard`，手机打开 `https://babelbeast.com/xks`，不使用手机自身的 `127.0.0.1`。本地独立开发入口仍为 `bash scripts/demo.sh start`，默认本机页面带 `/xks` 前缀，不与正式服务争用端口。安装与构建见 [演示网页运行](演示网页运行.md)，正式部署见 [域名网页部署](域名网页部署.md)，手机流程见 [手机腰牌操作流程](../protocol/手机腰牌操作流程.md)。

确认一枚已登记腰牌、固定会话 `demo-001`、A点《秦俑归阵》、后台实物密钥及设备身份匹配。记录演示开始时的真实游戏进度；若已解锁或已有收藏，明确按复玩演示，不把现有进度说成新解锁或新奖励。不得为了开场整片擦除固件／存储、清空到访，或在未经批准时重置测试进度。

对接方负责 K230 实物扫码与屏幕操作。本项目只核对其上报契约、手机到访记录及后续腰牌流程。如果使用接口测试事件，须明确称为“接口测试到访”，不能宣称实际摄像头识别成功。生成模拟事件只能演示数据功能，不能用于实物解锁。

没有对接方扫码时，已授权的演示路径是选择001号并点击“测试打卡（A 点）”，然后连接、核对身份、认证同步及解锁；看板选择“接口联调测试”单独展示真实设备回执。它不计真实扫码，不能代替摄像头验收。001号目前已经解锁，必须按已有进度或复玩说明，不声称再次首次解锁。

为真实 AI 演示准备新鲜且有效的候选观测，所选到访不足九十秒，快照最长三十秒。已有五次真实 DeepSeek 调用的历史证据，详见 [模型阶段复核](../validation/网页域名与DeepSeek阶段复核.md)；历史证据不能代替现场新请求，也不能让过期候选恢复有效。当前正式接口测试只有A点观测，B/C无新鲜数据，页面会明确显示“无有效候选”。私有审计中的 `model_attempted` 本身不足以证明实网调用。私有密钥、内部令牌和未经检查的原始返回不要投屏。

## 三分钟路径

| 时间 | 现场动作 | 说明与可观察证据 |
| --- | --- | --- |
| 0:00—0:20 | 展示腰牌和真实起始进度 | “这是一枚可触摸的研学腰牌。”首次解锁演示要求游戏当前确实锁定；已有进度则直说复玩。 |
| 0:20—0:45 | 对接方扫码；工作人员选择同一到访 | 核对腰牌编号、A点、时间和来源。“到访先成为事实，推荐不会代替到访。”接口测试或模拟必须当场说明。 |
| 0:45—1:10 | 安卓手机连接，核对身份，认证同步，再解锁 | 演示者可操作，联调已授权由ADB控制；记录实物身份匹配。展示“已发送”和“设备已确认执行”的区别，只有真实认证回执才能说明执行成功。 |
| 1:10—1:45 | 腰牌本地完成三片拖拽拼接 | 按住碎片拖到轮廓内松手；展示一次拖错回原位，再正确通关。“手机只负责解锁，游戏在腰牌本地完成。”不把自动化替身当作触摸录像。 |
| 1:45—2:05 | 打开收藏并将奖励设为展示 | 展示真实收藏；已获得的奖励复玩后仍只有一份。需要时重新认证同步，后台只计设备确认的进度。 |
| 2:05—2:35 | 电脑看板展示来源、地图与新生成的下一站建议 | “这里统计的是参与腰牌五分钟去重到访，不是现场人数。”真实模型显示模型来源和输入依据；未配置／超时／故障则直说规则建议。B/C尚无触摸小游戏，只展示内容提示。 |
| 2:35—3:00 | 展示独立情景推演并收束 | 展示参数、单位和假设曲线。“这是给定假设的计算，不是已经降低拥堵的证据。”最后说明真实扫码、生成模拟、规则建议和模型建议各自的证据边界。 |

上述时段合计180秒。若手机授权或现场网络耗时超出时段，如实延长或停止该段，不预先记为五秒成功、不用假回执赶进度。重启持久化和三次断线验证应在正式计时演示前完成并留证，不能用三分钟演示替代三十分钟验收。

## 故障与备用材料

- 未匹配设备：停止写入，重新选择实际登记设备；不跳过身份核验。
- 已发送但未确认：说明结果未知，重连后先查认证进度；不重复宣布新解锁。
- 手机离线：已解锁游戏仍应本地可玩；恢复后重新认证同步。该行为必须实机验证。
- 节点数据不足／过期：保留灰色数据不足标记，不用旧快照冒充当前低热度。
- AI失败：展示真实规则来源或无建议；历史查询不是新模型调用，不延长有效期。
- 现场关键链路不可用：可以播放已录制并标注时间的真实操作录像，但必须说明是录像。当前尚无已验收实物备用录像；网页截图只能证明对应页面，不能替代实物执行。

备用材料建议放入被忽略的 `logs/`，先检查敏感信息并明确录制时间、版本和数据来源。固件含私有密钥，不作为公开附件分发。K230识别率、真实地理距离和安全容量不在本项目证据范围内，不能用代码测试推断。
